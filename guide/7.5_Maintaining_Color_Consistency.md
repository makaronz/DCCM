# 7.5 Maintaining Color Consistency

## Theory: Cross-Departmental Color Management

### Color Pipeline Consistency

**From Camera to Display:**
```
Camera (RAW/Log) → On-Set Grading (CDL/LUT) → Editorial (Proxy with CDL)
     ↓                    ↓                            ↓
Color Managed        CDL Embedded               CDL to Colorist
(ACES/Rec.709)      (ALE/XML)                   (Resolve/Baselight)
     ↓                    ↓                            ↓
Color Grading         VFX Pull                  Final Grade
(Primary + Look)   (CDL Applied)               (CDL + Creative)
     ↓                    ↓                            ↓
Deliverables        QC Reference               Final Master
(DCP/IMF/PQR)      (Color Accuracy)           (Color Verified)
```

**Consistency Checkpoints:**
1. **On-Set**: DIT creates CDL for shot matching, reference monitoring (Rec.709/P3)
2. **Editorial**: Proxy files with embedded CDL (graded look preserved in offline edit)
3. **VFX**: Pulls with CDL applied (color-managed pipeline, avoid re-grading)
4. **Color Grading**: CDL as starting point (on-set primary grade, add creative look)
5. **QC/Final Master**: Verify color consistency (shot matching, look adherence, delivery format)

**Break Points:**
- **On-Set to Editorial**: CDL not embedded in proxy files, or wrong CDL format
- **Editorial to VFX**: CDL not applied to VFX pulls (flat footage, wrong color space)
- **VFX to Color**: VFX delivered with wrong color space (not matching on-set decisions)
- **Color to Final**: Delivery format wrong color space (Rec.709 vs P3 vs HDR)

### Shot-to-Shot Matching

**Primary Matching Tools (CDL):**
- **Exposure Matching**: Slope (contrast) + Offset (brightness) to match brightness between shots
- **White Balance Matching**: RGB Slope/Offset to match color temperature (warm vs cool)
- **Saturation Matching**: SAT value to match color richness (desaturated vs saturated)
- **Gamma Matching**: Power (gamma) to match midtone contrast (lifted vs crushed midtones)

**Secondary Matching (Beyond CDL):**
- **Selective Saturation**: Boosting desaturated areas (skin tones, sky)
- **Selective Brightness**: Power windows (lift shadows, darken highlights)
- **Color Matching**: Hue vs hue (matching skin tones, sky color, foliage)
- **Film Grain Matching**: Adding grain to match film stocks or high-ISO footage

**Matching Workflow:**
1. **Establish Hero Shot**: Best-looking take as reference (correct exposure, white balance, composition)
2. **Match to Hero**: Apply CDL to other shots (match exposure, white balance, saturation)
3. **Fine-Tune**: Secondary corrections (power windows, selective color, grain)
4. **Verify**: Check shot-to-shot consistency (toggle between shots, look for jumps)

### Color Script and Creative Intent

**Color Script Fundamentals:**
- **Purpose**: Visual guide for color progression (location, time of day, emotional arc)
- **Components**: Color swatches, reference images, mood boards, technical notes (LUTs, CDL values)
- **Uses**: Communicate creative vision (DP → DIT → Colorist), ensure consistency across scenes

**Color Script Elements:**
- **Location-Based Looks**: Day exterior (warm, saturated), night interior (cool, desaturated), etc.
- **Time Progression**: Morning (warm), noon (neutral), sunset (warm), night (cool)
- **Emotional Arc**: Happy scenes (warm, saturated), sad scenes (cool, desaturated), tense scenes (high contrast)
- **Character-Based Looks**: Different color palettes for different characters/locations

**Implementing Color Script:**
1. **Pre-Production**: DP and colorist create color script (reference images, test footage)
2. **On-Set**: DIT receives color script (reference looks, LUTs, CDL presets)
3. **Production**: DIT applies looks on-set (day exterior = warm look, night = cool look)
4. **Post**: Colorist refines looks (match on-set decisions, add creative nuance)

**Deviation from Color Script:**
- **Lighting Changes**: Weather, time of day, location constraints (adapt look to conditions)
- **Creative Changes**: Director changes vision (new look needed, update color script)
- **Technical Constraints**: Camera limitations, color space issues (work within constraints)
- **Communication**: Update colorist immediately (don't wait until post)

## Practice: Communication and Quality Control

### Department Communication Protocols

**On-Set to Editorial Communication:**
- **Daily CDL Export**: Send CDL files (ALE/XML) with dailies (embed CDL in proxy files)
- **Color Reports**: PDF/CSV report with shot metadata (CDL values, thumbnails, notes)
- **LUT Library**: Send LUTs used on-set (display LUTs, creative LUTs, camera matching LUTs)
- **Camera Reports**: ISO, white balance, exposure index, lens info (helps with shot matching)

**Editorial to VFX Communication:**
- **VFX Pulls with CDL**: Send graded footage (with on-set CDL applied) instead of flat footage
- **Color Space Documentation**: Specify working color space (ACES, Rec.709, P3) for VFX pipeline
- **LUT Instructions**: Provide LUTs for preview (VFX artists view graded look while working)
- **Shot Notes**: Communicate creative intent (match on-set grade, don't re-grade, follow color script)

**VFX to Color Communication:**
- **Deliver in Agreed Color Space**: ACES, Rec.709, or P3 (match on-set and editorial decisions)
- **Include CDL in Metadata**: Embed on-set CDL (don't strip metadata when rendering)
- **Preview LUTs**: Provide LUTs for colorist preview (how VFX should look with grade applied)
- **Shot Status**: Flag shots with color issues (notify colorist before grading session)

**Colorist to On-Set Communication:**
- **Reference Grades**: Send graded reference shots (on-set DIT matches to colorist's work)
- **LUT Updates**: Update display LUTs (if on-set LUTs are wrong, send corrected versions)
- **Feedback Loop**: Colorist reviews on-set CDLs (provides feedback on matching, creative decisions)
- **Final Grade Communication**: Send final CDL values (on-set DIT updates for reshoots)

### Quality Control Workflow

**On-Set QC (DIT Responsibilities):**
- **Monitor Calibration**: Verify reference monitor (Rec.709 100 nits D65 gamma 2.4)
- **Color Accuracy Check**: Display color bars (verify flesh tone, blue, green)
- **Shot Matching**: Toggle between takes (ensure consistency within scene)
- **Metadata Verification**: Check CDL export (open ALE in text editor, verify values)

**Editorial QC (Assistant Editor Responsibilities):**
- **CDL Verification**: Import ALE into Media Composer (verify CDL columns populated)
- **Proxy Quality Check**: Spot-check proxy files (ensure CDL embedded, not flat)
- **Color Consistency**: Check edited sequence (look for shot-to-shot mismatches)
- **Communication**: Flag color issues (notify DP, DIT, colorist)

**VFX QC (VFX Supervisor Responsibilities):**
- **Color Pipeline Verification**: Test on-set CDL (apply to footage, verify match to on-set look)
- **Shot Matching**: Match VFX shots to on-set grade (don't re-grade from scratch)
- **Color Space Check**: Verify working color space (ACES, Rec.709, P3)
- **Preview LUTs**: Apply on-set LUT (preview final look while working)

**Color Grading QC (Colorist Responsibilities):**
- **On-Set CDL Review**: Load on-set CDLs (verify shot matching, creative intent)
- **Color Script Adherence**: Follow color script (day exterior warm, night interior cool)
- **Shot Matching**: Match all shots in scene (primary matching with CDL, secondary with power windows)
- **Final Grade Verification**: Check entire project (consistency across scenes, locations, time)

### Version Control and Documentation

**CDL Versioning:**
- **Naming Convention**: `ProjectName_SceneX_TakeY_Date_v01.cdl`
- **Version Numbers**: Increment for each revision (v01 initial, v02 refined, v03 final)
- **Backup Strategy**: Save all versions (don't overwrite), archive after project completion
- **Documentation**: Track changes between versions (why CDL was adjusted, who approved)

**LUT Version Control:**
- **LUT Library Organization**: Display LUTs (camera log to Rec.709), Creative LUTs (looks), Utility LUTs (color space conversion)
- **Version Tracking**: LUT v1, LUT v2 (document changes: gamma adjustment, color shift)
- **Distribution**: Email/shared storage for LUT updates (notify all departments)
- **Archive**: Final LUT library (store with project deliverables, LTO tape)

**Documentation Deliverables:**
- **On-Set Reports**: PDF with shot metadata, CDL values, thumbnails, notes (daily or end of day)
- **Color Script**: Visual guide (reference images, color swatches, mood boards)
- **LUT Documentation**: LUT names, descriptions, when/where to use each LUT
- **Communication Log**: Email thread, Slack messages, meeting notes (decisions, changes, approvals)

### Color Consistency Verification

**Shot Matching Tests:**
- **Toggle Test**: Rapidly switch between shots (look for exposure jumps, color shifts)
- **Side-by-Side**: Display two shots simultaneously (compare skin tones, sky, foliage)
- **Scope Analysis**: Waveform/vectorscope (match exposure, white balance, saturation)
- **Reference Comparison**: Compare to hero shot (ensure all shots match)

**Color Script Verification:**
- **Scene-by-Scene Check**: Verify each scene matches color script (day exterior = warm, night = cool)
- **Progression Check**: Verify color progression (morning → noon → sunset → night)
- **Character Check**: Verify character-based looks (consistent color palette for each character)
- **Emotional Arc Check**: Verify color matches emotional tone (happy = warm, sad = cool)

**Technical Verification:**
- **Color Space Check**: Verify all shots in correct color space (Rec.709, P3, ACES)
- **Gamma Check**: Verify gamma (Rec.709 = gamma 2.4, DCI-P3 = gamma 2.6)
- **White Point Check**: Verify white point (D65 for Rec.709/Rec.2020, DCI for P3)
- **Bit Depth Check**: Verify sufficient bit depth (10-bit for grading, 8-bit for delivery)

## Failure Modes: Inconsistency and Communication

### Inconsistent Looks

**Shot Matching Failures:**
- **Symptom**: Exposure jumps between shots (too dark/bright), color shifts (warm to cool)
- **Cause**: CDL not applied correctly, wrong CDL values, or missing CDL for certain shots
- **Fix**: Re-apply CDL (verify timecode matches, check CDL values), manually match shots in grading
- **Prevention**: Spot-check shot matching on-set (toggle between takes), communicate CDL issues immediately

**Color Script Violations:**
- **Symptom**: Day exterior looks cool (should be warm), night interior looks warm (should be cool)
- **Cause**: DIT didn't receive color script, or creative changes not communicated
- **Fix**: Update color script (communicate changes to all departments), re-grade shots to match
- **Prevention**: Distribute color script before shoot (DIT, editorial, VFX, colorist), update promptly if vision changes

**Camera Mismatches:**
- **Symptom**: Different cameras (A-camera vs B-camera) have different looks (color, contrast)
- **Cause**: Different cameras not matched (different LUTs, CDLs, or color science)
- **Fix**: Create camera matching LUT (normalize all cameras to consistent look), apply CDL on top
- **Prevention**: Test camera matching before shoot (shoot test with all cameras, match in grading)

**Lighting Inconsistencies:**
- **Symptom**: Same location, different days have different looks (sunlight vs overcast)
- **Cause**: Weather changes, time of day changes, lighting setup changes
- **Fix**: Grade to match (adjust CDL to match hero shot), or accept inconsistency (document intentional choices)
- **Prevention**: Scout locations (anticipate lighting changes), communicate with gaffer (maintain consistency)

### Communication Breakdown

**On-Set to Editorial Disconnect:**
- **Symptom**: Editorial receives flat files (no CDL), or wrong CDL (doesn't match on-set look)
- **Cause**: CDL not sent with dailies, or wrong CDL format (incompatible with editorial system)
- **Fix**: Re-send CDLs (correct format, embed in proxy files), verify editorial received and applied
- **Prevention**: Test CDL workflow before shoot (on-set → editorial → back to on-set), verify compatibility

**Editorial to VFX Disconnect:**
- **Symptom**: VFX receives flat footage (no CDL), wrong color space (not matching on-set decisions)
- **Cause**: Editorial didn't send CDL with VFX pulls, or VFX ignored CDL and re-graded
- **Fix**: Re-send VFX pulls with CDL applied, communicate color space requirements
- **Prevention**: Include VFX supervisor in color pipeline discussions, test VFX pull workflow before shoot

**VFX to Color Disconnect:**
- **Symptom**: VFX shots don't match on-set grade (different exposure, white balance, saturation)
- **Cause**: VFX delivered in wrong color space, or didn't apply on-set CDL
- **Fix**: Re-render VFX in correct color space, re-apply on-set CDL
- **Prevention**: Involve colorist in VFS pipeline planning, test VFS integration before final render

**Colorist to On-Set Disconnect:**
- **Symptom**: On-set DIT doesn't know colorist's creative decisions (wrong LUTs, CDLs)
- **Cause**: Colorist didn't communicate reference grades, or DIT didn't receive updates
- **Fix**: Colorist sends reference grades (CDL values, LUTs, graded stills), DIT matches on-set
- **Prevention**: Establish communication channel (Slack, email), regular check-ins (daily or weekly)

### Version Mismatches

**CDL Version Confusion:**
- **Symptom**: Post receives multiple CDL versions (confusion about which is final)
- **Cause**: Poor version control (multiple CDL exports, no clear naming convention)
- **Fix**: Establish version control (v01, v02, v03), document which version is final, archive old versions
- **Prevention**: Use CDL management software (LiveGrade library, ShotHub), single source of truth

**LUT Version Confusion:**
- **Symptom**: On-set using LUT v1, post using LUT v2 (different looks)
- **Cause**: LUT updated during production (new version created), not communicated to all departments
- **Fix**: Distribute updated LUTs to all departments (email, shared storage), document LUT versions
- **Prevention**: Centralized LUT library (shared storage, cloud), email/notification for LUT updates

**Creative Changes Not Communicated:**
- **Symptom**: On-set grade doesn't match final grade (director changed look in post)
- **Cause**: Creative vision evolved (director/DP changes mind), not communicated to on-set team
- **Fix**: Document creative changes (email on-set team, update color script), re-grade on-set if needed
- **Prevention**: Manage expectations (on-set CDL is starting point, not final grade), communicate early if look changes

### Technical Inconsistencies

**Color Space Mismatches:**
- **Symptom**: Shot looks wrong (washed out, oversaturated) due to wrong color space
- **Cause**: Rec.709 footage displayed on P3 monitor, or P3 footage on Rec.709
- **Fix**: Convert to correct color space (use color management: ACES, LUTs)
- **Prevention**: Document color space for each stage (on-set, editorial, VFX, color, delivery)

**Gamma Mismatches:**
- **Symptom**: Image appears washed out (gamma too low) or too dark (gamma too high)
- **Cause**: Monitor gamma 2.2 but content expects 2.4, or gamma 2.4 displayed on gamma 2.2 monitor
- **Fix**: Re-calibrate monitor to correct gamma (Rec.709 = 2.4, DCI-P3 = 2.6)
- **Prevention**: Document gamma settings, verify calibration before critical grading

**Bit Depth Limitations:**
- **Symptom**: Banding in gradients (8-bit limitation), especially in wireless monitoring
- **Cause**: 8-bit display or codec (insufficient color precision for smooth gradients)
- **Fix**: Use 10-bit monitoring (OLED, high-end LCD), avoid 8-bit wireless for color decisions
- **Prevention**: Test monitoring setup before shoot (look for banding), accept 8-bit limitations for wireless

## Mini Glossary

- **Color Consistency**: Maintaining uniform color appearance across shots, scenes, departments, and from capture to final delivery

- **Shot Matching**: Using CDL (SOP+SAT) to match exposure, white balance, and saturation between takes within a scene

- **Color Script**: Visual guide (reference images, color swatches) communicating desired color progression (location, time of day, emotional arc)

- **QC (Quality Control)**: Verification process ensuring color accuracy, consistency, and adherence to creative intent at each stage of production

- **Version Control**: System for managing multiple versions of CDLs and LUTs (naming conventions, documentation, archiving)

- **Communication**: Ongoing dialogue between departments (on-set, editorial, VFX, color) ensuring creative intent preserved

- **Hero Shot**: Reference take within a scene (best exposure, white balance, composition) used to match all other shots

- **Primary Matching**: Adjusting exposure, white balance, and saturation using CDL (Slope, Offset, Power, Saturation)

- **Secondary Matching**: Fine-tuning beyond CDL (power windows, selective color, grain) for precise shot matching

- **Color Pipeline**: Managed color workflow from camera to final delivery (ACES or traditional) ensuring consistency and creative intent
