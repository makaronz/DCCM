# 7.2 Setting up Reference Monitors

## Theory: Monitor Technologies and Calibration

### Display Technologies

**OLED (Organic Light-Emitting Diode):**
- **Pros**: Perfect blacks (infinite contrast), wide color gamut (P3/Rec.2020), instant response time (no motion blur), viewing angle independence
- **Cons**: Limited peak brightness (500-700 nits for HDR, 200 nits for SDR), burn-in risk with static UI elements, expensive
- **Best For**: HDR grading, critical color decisions, dark room viewing
- **Models**: Sony BVM-HX310 (31" HDR reference), Atomos Sumo 19" (portable HDR), LG C3/G3 (consumer HDR reference)

**LCD/IPS (In-Plane Switching):**
- **Pros**: Higher peak brightness (1000-2000 nits for mini-LED), no burn-in, consistent color, affordable
- **Cons**: Lower contrast (1000:1 typical, 5000:1 with local dimming), viewing angle shifts, backlight bleed
- **Best For**: SDR grading, bright set environments, multi-viewer monitoring
- **Models**: Flanders Scientific CM250 (25" SDR reference), TVLogic LVM-246X (24" SDR), SmallHD Vision 24" (4K HDR)

**mini-LED with Local Diming:**
- **Pros**: High brightness (2000+ nits), HDR highlights, better contrast than standard LCD
- **Cons**: Blooming around bright objects (halo effect), inconsistent local dimming zones
- **Best For**: HDR monitoring in bright environments, client monitoring (less expensive than OLED)
- **Models**: Apple ProDisplay XDR (6K HDR reference), ASUS ProArt PA32UCX-K (32" HDR)

### Color Spaces and Gamma

**SDR Color Spaces:**
- **Rec.709**: Standard for HD broadcast, limited gamut (similar to P3 D65), gamma 2.4
- **P3 (DCI-P3)**: Digital cinema standard, wider gamut than Rec.709 (especially reds/greens), gamma 2.6
- **Rec.2020**: Ultra HD standard, widest gamut (future-proof), but most content mastered in P3

**HDR Color Spaces:**
- **PQ (Perceptual Quantizer / SMPTE ST 2084)**: Used for Dolby Vision, HDR10+, absolute brightness (nits), 10,000 nits peak capability
- **HLG (Hybrid Log-Gamma)**: Used for BBC/NHK HDR broadcast, backward compatible with SDR, relative brightness
- **HDR10**: Consumer HDR standard (10-bit, Rec.2020, PQ), static metadata (no dynamic metadata like Dolby Vision)

**Gamma Curves:**
- **Gamma 2.4**: Standard Rec.709 gamma for broadcast monitoring
- **Gamma 2.6**: DCI-P3 gamma for digital cinema projection
- **BT.1886**: Standard for HD monitoring (similar to gamma 2.4 but with black level compensation)
- **sRGB**: Computer display gamma (2.2), NOT suitable for video grading

**White Point:**
- **D65**: Standard white point for Rec.709 and Rec.2020 (6500K, slightly warm)
- **DCI**: Digital cinema white point (slightly cooler than D65, used for P3)
- **Native**: Monitor's default white point (not recommended, inconsistent)

### Ambient Light and Viewing Environment

**Ambient Light Impact:**
- **Ideal**: Dark room (<5 lux) for critical color decisions, no light directly hitting screen
- **Acceptable**: Controlled lighting (neutral gray walls, 6500K bulbs), 25-50 lux ambient
- **Problematic**: Bright set (sunlight, overhead lights), windows, colored surfaces reflecting on screen

**Viewing Conditions:**
- **Contrast Perception**: Bright ambient reduces perceived contrast (darks appear lighter)
- **Color Perception**: Warm ambient light makes screen appear cool (blue shift), cool ambient makes screen appear warm
- **Guideline**: Monitor brightness should be 10x ambient light (e.g., 100 nits monitor for 10 lux room)

**Environment Setup:**
- **Wall Color**: Neutral gray (18% gray) behind monitor, no bright colors in peripheral vision
- **Lighting**: 6500K (D65) LED panels, dimmable, positioned to avoid screen reflections
- **Positioning**: Monitor at eye level, viewing distance 1-1.5x screen diagonal (30" monitor = 30-45" distance)

## Practice: Monitor Calibration Workflow

### Calibration Hardware

**Colorimeter Probes:**
- **X-Rite i1Display Pro Plus**: Industry standard, fast measurement, supports HDR (up to 2000 nits), LCD/OLED modes
- **X-Rite ColorMunki Display**: Consumer-level, slower, but accurate for SDR calibration
- **Portrait Displays C6 HDR2000**: Designed for Calman software, supports HDR up to 2000 nits
- **Klein K-10A**: Professional-level, high accuracy, expensive ($2000+), used for high-end calibration

**Calibration Software:**
- **Portrait Displays Calman**: Industry standard, supports most monitors, auto-calibration for Sony/Flanders
- **LightSpace CMS**: Advanced color management, 3D LUT generation, probe calibration
- **DisplayCAL**: Free/open-source, basic calibration, limited probe support
- **Built-in Tools**: Sony TrueColor, Flanders Remote Control (manufacturer-specific)

### SDR Monitor Calibration (Rec.709)

**Step 1: Preparation (30 minutes before calibration):**
- Warm up monitor for 30 minutes (stabilizes backlight)
- Clean screen (microfiber cloth, no streaks)
- Set ambient light to target (25 lux for grading suite)
- Position probe (suction cup or tripod center screen)

**Step 2: Initial Settings:**
- Reset monitor to factory defaults (clears previous calibration)
- Set color temperature to D65 (6500K)
- Set gamma to 2.4 (or BT.1886)
- Disable auto-brightness, eco mode, dynamic contrast
- Set brightness to 100 nits (cd/m²) for Rec.709 grading

**Step 3: Calibration (10-20 minutes):**
- Run auto-calibration (Calman → AutoCal for supported monitors)
- Software measures primaries, secondaries, white point, gamma, grayscale
- Adjusts internal monitor LUTs to hit Rec.709 targets
- Generates calibration report (delta E < 2.0 is acceptable, <1.0 is excellent)

**Step 4: Verification (5 minutes):**
- Display calibration patches (100% white, 100% red/green/blue, grayscale steps)
- Verify with probe (measure actual vs target)
- Check color accuracy (delta E), gamma tracking, white point
- Print/save calibration report for documentation

**Step 5: Ongoing Maintenance:**
- Recalibrate monthly (professional use) or quarterly (light use)
- Verify weekly with quick probe check (grayscale only)
- Re-calibrate if monitor is moved or environmental conditions change

### HDR Monitor Calibration (PQ/HLG)

**Step 1: HDR Setup (additional to SDR prep):**
- Enable HDR mode on monitor (PQ for Dolby Vision, HLG for broadcast)
- Set peak brightness target (1000 nits for HDR10 reference, 700 nits for Dolby Vision)
- Set color gamut to P3 or Rec.2020 (depending on content)
- Enable local diming (if available) for better contrast

**Step 2: HDR Calibration (20-30 minutes):**
- Calibrate for 100 nits first (SDR baseline, matches PQ/HLG mid-point)
- Calibrate peak brightness (measure at 10%, 25%, 50%, 75%, 100% stimulus)
- Adjust EOTF (Electro-Optical Transfer Function) to track PQ or HLG curve
- Verify color gamut (P3 primaries, Rec.2020 if supported)
- Check tone mapping (smooth roll-off at peak brightness, no clipping)

**Step 3: HDR Verification:**
- Display HDR test patterns (1000 nits peak, 4000 nits peak if supported)
- Measure actual brightness vs target (within 10% tolerance)
- Check color volume (P3 color at various brightness levels)
- Verify black level (OLED should be <0.0005 nits, mini-LED <0.05 nits)
- Test with HDR content (Dolby Vision demo reels, HDR10+ samples)

**Step 4: Documentation:**
- Save HDR calibration profile (PQ-1000nits-P3, HLG-600nits-Rec.2020)
- Export calibration report (EOTF tracking, color gamut, delta E)
- Document ambient light conditions (critical for HDR perception)
- Label monitor with calibration date and profile used

### Multi-Monitor Matching

**Cross-Platform Calibration:**
- **Goal**: Match multiple monitors (DIT cart, client monitor, director's view) within delta E 2.0
- **Method**: Calibrate all monitors to same target (Rec.709 100 nits D65 gamma 2.4)
- **Verification**: Display same test pattern on all monitors, compare with probe
- **Adjustment**: Fine-tune brightness/contrast to match, avoid changing color temperature

**Common Pitfalls:**
- **Different Technologies**: OLED blacks vs LCD blacks will never match perfectly (contrast ratio difference)
- **Panel Aging**: Older monitors drift over time (backlight dimming, color shift)
- **Viewing Angles**: IPS monitors shift color off-axis, position viewers centrally
- **Solution**: Use same monitor model for critical matching, calibrate regularly, accept slight differences

## Failure Modes: Calibration and Environmental

### Wrong Calibration

**Incorrect Color Space:**
- **Symptom**: Colors look wrong (skin tones too red/magenta, greens shift to cyan)
- **Cause**: Monitor calibrated to P3 but grading for Rec.709 delivery, or using sRGB mode for video
- **Fix**: Re-calibrate to correct color space (Rec.709 for HD broadcast, P3 for digital cinema)
- **Prevention**: Document delivery format in camera report, label monitor with calibration profile

**Gamma Mismatch:**
- **Symptom**: Image appears washed out (gamma too low) or too dark (gamma too high), midtones wrong
- **Cause**: Monitor gamma 2.2 but software expects 2.4, or Rec.709 content on sRGB display
- **Fix**: Verify gamma setting in monitor menu (2.4 for Rec.709, 2.6 for DCI-P3), re-calibrate if needed
- **Prevention**: Use calibration software that locks gamma (BT.1886 recommended), document gamma setting

**White Point Drift:**
- **Symptom**: Image appears too warm (yellow) or too cool (blue), inconsistent skin tones
- **Cause**: Monitor white point drifted from D65 to native (9300K or cooler), or ambient light shifted perception
- **Fix**: Re-measure white point with probe, adjust monitor color temperature control, verify with D65 patch
- **Prevention**: Calibrate monthly, verify white point weekly, control ambient light (6500K bulbs)

### Monitor Drift Over Time

**Backlight Aging (LCD):**
- **Symptom**: Monitor gets dimmer over time (months/years), colors shift (blues become green)
- **Cause**: LED backlight degrades (brightness decreases, color temperature shifts)
- **Fix**: Increase brightness to maintain 100 nits, re-calibrate color, replace backlight if unusable
- **Prevention**: Calibrate quarterly, track brightness over time (log calibration results), plan for replacement after 3-5 years

**OLED Burn-In:**
- **Symptom**: Ghost images of static UI (timecode, scopes), color unevenness (one area darker)
- **Cause**: Static elements displayed for hours (software interface, channel logos), same aspect ratio content
- **Fix**: Run screen refresh cycle (flashing colors pattern), reduce brightness to slow burn-in, replace panel if severe
- **Prevention**: Hide UI elements when not grading, use full-screen content, vary content (letterbox vs full screen), enable pixel shift (if available)

**Colorimeter Drift:**
- **Symptom**: Calibration gets worse over time (delta E increases), inconsistent results
- **Cause**: Probe sensor degrades (dust, age), needs recalibration by manufacturer
- **Fix**: Send probe to manufacturer for recalibration (yearly for professional use), upgrade to new probe
- **Prevention**: Store probe in case (protect from dust/UV), handle carefully (don't drop), keep calibration certificate current

### Ambient Light Impact

**Bright Set Conditions:**
- **Symptom**: Can't see shadow detail, colors appear washed out, grading decisions change when lights dim
- **Cause**: Ambient light >50 lux (bright sunlight, overhead studio lights), reflections on screen
- **Fix**: Grade in darker environment (tent/cover over monitor), increase monitor brightness (120-150 nits temporarily)
- **Prevention**: Use monitor hood (blocks side light), grade in controlled environment, defer critical grading to post

**Colored Ambient Light:**
- **Symptom**: Monitor appears to shift color (warm room → cool image, blue walls → magenta image)
- **Cause**: Wall color reflects on screen, tungsten lighting (3200K) makes D65 monitor appear blue
- **Fix**: Neutral gray environment, paint walls 18% gray, use 6500K lighting (daylight-balanced)
- **Prevention**: Grade in neutral environment, position monitor away from colored surfaces, use matte screen (less reflective)

**Viewing Angle Shifts (LCD):**
- **Symptom**: Client off-center sees different colors (skin tones shift, blacks lighten)
- **Cause**: IPS panels shift color/brightness at extreme angles (>30 degrees off-center)
- **Fix**: Position viewers directly in front of monitor (within 30 degrees), use OLED (better viewing angle)
- **Prevention**: Use larger monitor so more viewers can sit centered, or multiple client monitors, educate about viewing angles

### Wrong Color Space Selection

**Grading HDR on SDR Monitor:**
- **Symptom**: HDR highlights clipped (washed out), colors wrong (gamut mismatch), can't judge exposure
- **Cause**: Rec.2020/P3 HDR content displayed on Rec.709 SDR monitor (gamut clipping)
- **Fix**: Use HDR monitor for HDR grading (OLED or mini-LED with HDR support), or tone map to SDR
- **Prevention**: Know delivery format before shoot (HDR vs SDR), rent HDR monitor if needed

**Grading SDR on HDR Monitor:**
- **Symptom**: Image appears too dark (monitor set to 1000 nits but content is 100 nits), colors oversaturated
- **Cause**: HDR monitor in HDR mode displaying SDR content (wrong EOTF)
- **Fix**: Switch monitor to SDR mode (Rec.709 gamma 2.4, 100 nits), or use HDR monitor in SDR mode
- **Prevention**: Test monitoring setup before shoot (display SDR test pattern, verify 100 nits)

**P3 vs Rec.709 Mismatch:**
- **Symptom**: Reds/oranges too saturated, skin tones wrong, colors outside Rec.709 gamut
- **Cause**: Grading in P3 on set but delivering Rec.709 (broadcast), or vice versa
- **Fix**: Calibrate monitor to delivery color space (Rec.709 for HD, P3 for digital cinema)
- **Prevention**: Document delivery format in camera report, use software color management (ACES handles conversions)

## Mini Glossary

- **Reference Monitor**: Professional-grade display with accurate color, calibration, and consistency for critical color evaluation (not consumer TVs)

- **Calibration Probe**: Hardware device (colorimeter) measuring screen color and brightness to adjust monitor to target standards (Rec.709, P3, HDR)

- **Ambient Light**: Environmental lighting affecting monitor perception (ideal: <5 lux dark room, acceptable: 25-50 lux controlled lighting)

- **Nits**: Unit of brightness (cd/m²), SDR reference monitors target 100 nits, HDR targets 600-4000 nits

- **White Point**: Color temperature of white (D65 = 6500K for Rec.709/Rec.2020, DCI for digital cinema), critical for accurate color reproduction

- **Gamma**: Power curve relating input signal to output brightness (gamma 2.4 for Rec.709, gamma 2.6 for DCI-P3), affects midtone reproduction

- **Delta E**: Metric for color difference (delta E < 2.0 imperceptible, delta E > 5.0 noticeable), used to verify calibration accuracy

- **EOTF (Electro-Optical Transfer Function)**: HDR gamma curve (PQ for Dolby Vision, HLG for broadcast), mapping signal to absolute brightness (nits)

- **Local Diming**: LCD technology selectively dimming backlight zones for better contrast (mini-LED has hundreds/thousands of zones)

- **BT.1886**: Standard gamma for HD monitoring (similar to gamma 2.4 but with black level compensation for CRT legacy)
