# 7.1 On-Set Hardware and Software

## Theory: DIT Cart Architecture and Signal Flow

### Modern DIT Cart Topology

**Signal Flow Architecture:**
```
Camera → SDI (12G/6G/3G) → DIT Cart → Distribution → Monitoring/Recording
   ↓                      ↓            ↓
Raw Metadata          Processing     CDL/LUT
                      (LiveGrade)   Embedding
                           ↓
                      Color Pipeline
                      (ACES/Rec.709)
```

**Core Processing Path:**
1. **Video Ingest**: 12G-SDI for 4K+ RGB, 6G/3G for HD or YCbCr
2. **Color Management**: Input transform (camera log) → Working color space (Rec.709/2020/P3)
3. **Look Application**: CDL/LUT overlay on managed color
4. **Distribution**: Multiple SDI outputs with independent look assignments
5. **Recording**: Compressed proxies with embedded CDL, raw backups

### Color Management on Set

**ACES Pipeline:**
- **Input Transform**: IDT (Input Device Transform) matches camera sensor characteristics
- **Working Color Space**: ACES2065-1 (scene-referred) for maximum color fidelity
- **Output Transform**: Rec.709 (SDR) or Rec.2020/P3 (HDR) for client monitoring
- **Look**: Creative grade applied between ACES and RRT/ODT

**Traditional Pipeline:**
- **Camera Log**: REDLogFilm, S-Log3, V-Log, C-Log (camera-specific)
- **Display LUT**: 1D or 3D LUT mapping log to Rec.709 for monitoring
- **CDL**: Primary grade applied before LUT for shot matching

**Metadata Preservation:**
- **Camera Metadata**: ISO, white balance, exposure index, shutter angle
- **Color Decisions**: CDL values (SOP), LUT references, transform IDs
- **Timecode**: Continuous jam-sync from master clock
- **Audio Embedding**: Reference track for editorial sync

## Practice: Hardware and Software Setup

### Essential Hardware

**DIT Cart Core:**
- **Computer**: MacBook Pro M3 Max (16" with 36GB RAM unified memory) or PC workstation (Threadripper, RTX 4090)
- **I/O**: Blackmagic Design DeckLink 8K Pro or UltraStudio 4K
- **Monitoring**: 17" or 24" reference monitor (OLED for HDR, IPS for SDR)
- **Storage**: NVMe SSD RAID (8TB+) for real-time offload and backup
- **Power**: UPS battery backup, regulated power distribution

**Connectivity:**
- **SDI**: 12G-SDI for single-cable 4K, quad-link for older infrastructure
- **Ethernet**: 10GbE for high-speed network storage, Time Machine support
- **Wireless**: Teradek Bolt 4K or SmallHD Focus Bolt for client monitoring
- **USB-C/Thunderbolt**: Fast SSD offload (2GB/s+ with Samsung T7 Shield)

**Monitoring Solutions:**
- **Client Monitor**: 7" or 13" wireless monitor with LUT support (SmallHD, TVLogic)
- **Scope**: Built-in scopes in LiveGrade/Resolve for waveform, vectorscope, parade
- **Colorimeter**: X-Rite i1Display Pro for calibration verification

### Software Ecosystem

**Live Grading:**
- **Pomfort LiveGrade Pro**: Industry standard, CDL/LUT management, metadata handling
  - **Features**: Unlimited CDL/LUT slots, shot library, ALE export
  - **Integration**: Silverstack for media management, ShotHub for cloud collaboration
  - **Workflow**: Real-time color correction, automatic CDL save with timecode

- **ColorFront Engine**: Cloud-enabled, ACES-aware, multi-camera synchronization
  - **Features**: Automated color matching, AI-powered shot balancing
  - **Collaboration**: Real-time grading with remote colorists, version control
  - **Workflow**: On-set grading → Cloud sync → Post continuity

- **DaVinci Resolve Studio**: Full grading power on-set (limited by GPU)
  - **Features**: Node-based grading, noise reduction, stabilization
  - **Limitations**: GPU dependency (RTX 4090 recommended for 8K), UI complexity
  - **Workflow**: Live grading → Project export → Post handoff

**Media Management:**
- **Pomfort Silverstack**: Offload, verification, metadata management
  - **Checksum**: MD5/xxHash verification for bit-for-bit copies
  - **Library**: Shot organization, metadata tagging, CDL linking
  - **Export**: ALE, PDF reports, EDL for editorial

- **Imagine Products ShotPut Pro**: Automated offload with progress tracking
  - **Features**: Multi-destination copies, verification, reporting
  - **Integration**: Direct to LTO archival, cloud upload

**Utility Tools:**
- **ScopeBox**: Software-based waveform/vectorscope for iPad
- **LUT Utility**: Convert between Cube, 3DL, Spi3D formats
- **Frame.io**: Camera-to-cloud delivery for immediate review

### Real-Time Grading Workflow

**1. Pre-Setup (Before Shoot):**
- Import camera IDTs (ACES) or manufacturer LUTs
- Create look library (day exterior, night interior, etc.)
- Set up output transforms (Rec.709 for video village, P3 for DIT)
- Configure SDI routing (clean feed vs graded output)

**2. On-Set Grading:**
- Apply IDT/LUT for monitoring (log → Rec.709)
- Adjust CDL for shot matching (lift/gamma/gain + saturation)
- Save CDL with timecode stamp (auto-embed in proxy files)
- Export ALE (ALE XML) with CDL values for editorial

**3. Data Handoff:**
- Deliver camera originals (raw) with embedded CDL
- Provide proxy files (ProRes 422 LT) with baked LUT
- Export LUT library (1D/3D) for post reference
- Generate report (PDF/CSV) with shot metadata, grades, notes

## Failure Modes: Signal Integrity and Metadata

### Signal Integrity Issues

**Bandwidth Limitations:**
- **Symptom**: 4K signal drops to HD, artifacts, frozen frame
- **Cause**: 12G-SDI cable length >50ft, bending radius <1.5", BNC damage
- **Fix**: Use fiber optic extenders (Single Link 4K over single fiber), certified 12G BNC connectors
- **Prevention**: Cable testers (Sencore), keep spares on set

**Color Space Conversion Errors:**
- **Symptom**: Washed out image, incorrect colors, clipping
- **Cause**: Wrong SDI color space (YCbCr vs RGB), bit depth mismatch (10-bit vs 8-bit)
- **Fix**: Verify camera output settings (RGB 4:4:4 12-bit for grading), matching SDI input
- **Prevention**: Test signal flow before principal photography, document camera output format

**Wireless Compression:**
- **Symptom**: Banding in gradients, macroblocking in shadows, color shifting
- **Cause**: Low bitrate wireless (<100Mbps), H.264 compression at long distance
- **Fix**: Raise bitrate (200Mbps+), shorten distance, use 5GHz band (not 2.4GHz)
- **Prevention**: Hardwired monitoring for critical color decisions, wireless for reference only

### LUT Path Failures

**Wrong LUT Chain:**
- **Symptom**: Image looks wrong (too dark/washed out), colors shifted
- **Cause**: CDL applied after LUT (should be before), double LUT application, missing IDT
- **Fix**: Verify processing order: Camera Log → CDL → Display LUT → Output Transform
- **Prevention**: Document LUT chain in DIT report, use software that enforces correct order

**LUT Format Incompatibility:**
- **Symptom**: LUT not loading, colors wrong, software crash
- **Cause**: 3D LUT size mismatch (33x33x33 vs 65x65x65), wrong format (.cube vs .3dl)
- **Fix**: Convert using LUT Utility, verify bit depth (8-bit vs 12-bit LUT)
- **Prevention**: Test all LUTs before shoot, keep multiple formats on hand

**Missing LUT Updates:**
- **Symptom**: Different looks between camera models (RED vs ARRI vs Sony)
- **Cause**: Manufacturer LUTs outdated (firmware changes), custom LUT not applied to all cameras
- **Fix**: Re-download latest LUTs from manufacturer, test cross-camera matching
- **Prevention**: Create unified look LUT that normalizes camera differences

### Metadata Loss

**CDL Not Embedding:**
- **Symptom**: Post receives flat files (no grade applied), ALE empty
- **Cause**: Software export failure, timecode mismatch between CDL and clips, format incompatibility
- **Fix**: Verify CDL export (open ALE in text editor), match timecode format (HH:MM:SS:FF), re-export
- **Prevention**: Test CDL round-trip (on-set → post → back to on-set), use XML/JSON for flexibility

**Timecode Breaks:**
- **Symptom**: CDL applied to wrong shot, mismatched grades in post
- **Cause**: Camera free-run vs record run, jam-sync failure, battery replacement reset
- **Fix**: Re-jam timecode daily, use continuous timecode (don't reset for each take)
- **Prevention**: Master timecode clock on set, jam all cameras daily, document in camera reports

**Camera Metadata Loss:**
- **Symptom**: Wrong ISO/color temp applied in post, white balance drift
- **Cause**: Raw file metadata not read correctly, sidecar (.XML) missing
- **Fix**: Use manufacturer software (REDCINE-X, Sony RAW Viewer) to verify metadata
- **Prevention**: Include camera reports (PDF) with metadata as backup, embed in proxy files

## Mini Glossary

- **DIT Cart**: Mobile color grading station on set with computer, I/O, monitoring, and storage for real-time color decisions and data management

- **Signal Flow**: Path of video signal from camera through processing (color grading, LUT application) to monitoring and recording systems

- **Metadata Preservation**: Maintaining camera and color information (ISO, CDL, timecode) with video files for post-production continuity

- **LUT Path**: Order of color transformations: Camera Log → CDL → Display LUT → Output Transform, critical for accurate monitoring

- **Color Management**: System of transforms ensuring consistent color across capture, on-set monitoring, post-production, and final display (ACES or traditional)

- **Live Grade**: Real-time color correction applied on set for immediate client feedback, shot matching, and post-production reference

- **IDT (Input Device Transform)**: ACES transform converting camera-specific log encoding to scene-referred ACES color space

- **SDI (Serial Digital Interface)**: Industry-standard cabling for video transmission (3G, 6G, 12G) supporting uncompressed video up to 8K

- **ALE (Avid Log Exchange)**: File format (.ale or .xml) containing shot metadata, CDL values, and timecode for editorial import

- **Checksum**: Mathematical verification (MD5, xxHash) ensuring bit-for-bit data accuracy during file offload and backup
