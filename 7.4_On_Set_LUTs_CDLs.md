# 7.4 Creating On-Set LUTs/CDLs

## Theory

### LUT Purpose and Function

A [LUT] (Look Up Table) is a mathematical model that maps input color values to output color values, enabling precise color transformations:

**Technical LUTs:**
- Convert camera Log/RAW to working color space (Rec.709, DCI-P3)
- Enable accurate monitoring on standard displays
- Maintain color fidelity through signal chain
- Typically 1D (gamma/gain) or 3D (full color volume)

**Creative LUTs:**
- Apply predetermined "looks" or styles
- Establish visual tone for production
- Enable consistent look across shots/scenes
- Always 3D for complex color manipulations

**On-Set LUT Applications:**
- Real-time look development
- Communication tool with post-production
- Reference for color continuity
- Starting point for final grade

### CDL Format and ASC-CDL

[CDL] (Color Decision List) is a standardized format for basic color corrections, defined by ASC-CDL (American Society of Cinematographers Color Decision List):

**ASC-CDL Components:**
1. **Slope**: Contrast/gain adjustment (multiplier, typically 0.0-10.0)
2. **Offset**: Lift/brightness adjustment (additive, typically -1.0 to 1.0)
3. **Power**: Gamma adjustment (exponential, typically 0.0-10.0)
4. **Saturation**: Overall color saturation (multiplier, typically 0.0-3.0)

**SOP Node Operation:**
- Applied per color channel (R, G, B independently)
- Order: Slope → Power → Offset (S-O-P order)
- Saturation applied to result of SOP operations
- Simple, deterministic, interoperable

**CDL Limitations:**
- Same adjustment applied to all colors
- No hue-specific or selective corrections
- No secondary color correction
- No spatial/temporal adjustments

### Color Decision List Workflow

The CDL workflow establishes a pipeline from on-set decisions to post-production:

**On-Set:**
- DIT creates CDLs during shooting
- Live grading with director/DP approval
- CDL values saved per shot/scene
- LUTs generated for monitoring

**Post-Production:**
- CDLs imported into grading system
- Applied as starting point for grade
- Can be refined or expanded
- Maintain continuity from set to grade

## Practice

### Building On-Set LUTs

**LUT Creation Workflow:**

1. **Establish Base Technical LUT**
   - Obtain camera manufacturer's official Log-to-Rec.709 LUT
   - Verify LUT accuracy with test charts
   - Test on actual footage (skin tones, gradients)
   - Save as "camera name + Log + to + Rec709 + technical"

2. **Create Creative Look Layers**
   - Start with technical LUT as base
   - Make creative adjustments in grading software
   - Adjustments typically include:
     - Contrast and tone curve adjustments
     - Color balance corrections (white balance, tint)
     - Saturation adjustments
     - Subtle hue shifts for stylistic effect
     - Shadow/highlight rolloff modifications

3. **Export as 3D LUT**
   - Format: .cube (most widely supported)
   - Size: 33x33x33 (good quality/size balance)
   - Bit depth: 16-bit integer or 32-bit float
   - Include metadata (description, creator, date)

4. **LUT Testing**
   - Apply to variety of content (skin tones, landscapes, interiors)
   - Check for banding in gradients
   - Verify saturation levels not excessive
   - Test on different monitors (reference and consumer)
   - Get approval from Director/DP

### CDL Creation Process

**On-Set CDL Workflow:**

1. **Setup Live Grading Environment**
   - Connect camera to DIT cart
   - Apply technical LUT for monitoring
   - Load reference clips from previous work
   - Calibrate reference monitor

2. **Make Color Decisions**
   - Adjust white balance and tint
   - Set exposure and contrast
   - Adjust saturation for overall look
   - Make subtle hue shifts if needed
   - Focus on overall image, not specific colors

3. **Create CDL Values**
   - Use CDL controls (Slope, Offset, Power, Saturation)
   - Adjust per channel if needed (R, G, B independently)
   - Keep adjustments subtle and reversible
   - Document creative intent

4. **Export CDL**
   - Format: .cdl (XML-based), .cc, .edl with embedded CDL
   - Include metadata (shot name, scene, take, date)
   - Backup to multiple locations
   - Send to post-production team

### Communication with Post

**Deliverables for Post-Production:**

1. **LUT Files**
   - Technical LUT (camera Log to working space)
   - Creative LUT (on-set look)
   - Both as .cube files
   - Include 1D and 3D versions if applicable

2. **CDL Files**
   - .cdl format (primary)
   - Backup formats (.cc, .edl)
   - Per-shot CDL values
   - Color grading decision lists

3. **Documentation**
   - Color workflow description
   - Monitor calibration reports
   - LUT/CDL application order
   - Contact information for questions

4. **Reference Frames**
   - Stills from approved takes
   - Before/after comparisons
   - Technical charts (skin tones, gradients)
   - Problematic examples

**Communication Best Practices:**

- **Pre-production meeting**: Discuss color workflow, deliverables, timeline
- **Daily updates**: Send new LUTs/CDLs to post team each shooting day
- **Reference materials**: Provide stills and notes explaining creative intent
- **Version control**: Track LUT/CDL versions (v1, v2, final)
- **Testing**: Verify post can apply LUTs/CDLs correctly before final delivery

## Failure Modes

### Wrong LUT Format

**Symptoms:**
- LUT won't load on post-production system
- Colors appear completely wrong
- Error messages about format incompatibility
- LUT applies but results are incorrect

**Causes:**
- Exported in unsupported format (.look vs .cube)
- Wrong bit depth (8-bit vs 16-bit vs 32-bit float)
- Incorrect LUT size (17x17x17 vs 33x33x33)
- Incompatible color space metadata

**Mitigation:**
- Always use .cube format (most widely supported)
- Use 33x33x33 size for quality/compatibility balance
- Test LUT on multiple systems before delivery
- Provide multiple formats (.cube, .3dl, .look)
- Document LUT specifications (size, bit depth, input/output space)

### Missing CDL Components

**Symptoms:**
- Colors don't match on-set look
- Skin tones appear different
- Contrast or saturation incorrect
- CDL applies but "missing something"

**Causes:**
- Only exported Slope, missing Offset/Power/Saturation
- Per-channel corrections not preserved
- CDL format didn't support all parameters
- Export/import errors truncated values

**Mitigation:**
- Always export complete SOP + Saturation
- Verify CDL file contains all 10 values (R/G/B SOP + Sat)
- Test CDL import on multiple systems
- Double-check values against original settings
- Provide CDL in multiple formats for safety

### Version Conflicts

**Symptoms:**
- Multiple versions of same LUT/CDL exist
- Confusion about which is current
- Post uses wrong version by mistake
- Cannot determine which version was approved

**Causes:**
- Poor version control (v1, v1.1, v2, final)
- Inconsistent naming conventions
- Multiple creators working independently
- Inadequate communication between set and post

**Mitigation:**
- Establish clear naming convention (project_scene_look_v03.cube)
- Use version control system (Git, dedicated server)
- Document changes between versions
- Single point of contact for LUT/CDL approval
- Destroy/obsolete old versions clearly
- Create "locked" or "final" versions when approved

### Color Mismatch

**Symptoms:**
- On-set look doesn't match post-production result
- Subtle color differences (skin tones, saturation)
- Contrast or brightness differences
- "Close but not quite" situation

**Causes:**
- Different monitoring environments (on-set vs grading suite)
- Monitor calibration differences
- LUT applied at wrong point in signal chain
- Color space conversions not accounted for

**Mitigation:**
- Calibrate on-set and post monitors to same standards
- Document entire signal path and color transforms
- Test LUT on both on-set and post systems
- Provide reference frames for comparison
- Schedule color review session if discrepancies persist
- Consider using ACES for color management consistency

## Mini Glossary

- **[LUT]** (Look Up Table): Mathematical model mapping input color values to output color values for color transformation, used for both technical and creative purposes.

- **[CDL]** (Color Decision List): Standardized format for basic color corrections using Slope, Offset, Power, and Saturation parameters, defined by ASC-CDL specification.

- **[ASC-CDL]** (American Society of Cinematographers Color Decision List): Industry standard defining format and exchange protocol for CDL data, ensuring interoperability between systems.

- **[Color decision]**: Creative determination of image appearance made during production, typically involving exposure, contrast, color balance, and saturation adjustments.

- **[Saturation]**: CDL parameter controlling overall color intensity, applied after SOP (Slope-Offset-Power) operations, typically 0.0 (desaturated) to 3.0 (oversaturated).

- **[Offset]**: CDL parameter (lift/brightness) adding or subtracting constant value to color channel, part of SOP operation sequence, range typically -1.0 to 1.0.

- **[Power]**: CDL parameter (gamma) affecting midtones of color channel through exponential adjustment, part of SOP operation sequence, range typically 0.0 to 10.0.

- **[Slope]**: CDL parameter (contrast/gain) multiplying color channel values, first operation in SOP sequence, range typically 0.0 to 10.0.

- **[SOP]**: Sequence of Slope, Offset, Power operations applied per color channel in CDL, fundamental building block of ASC-CDL color corrections.

- **[1D LUT]**: One-dimensional Look Up Table affecting only luminance/gamma, simpler than 3D LUT, used for basic contrast and tone adjustments.

- **[3D LUT]**: Three-dimensional Look Up Table affecting hue, saturation, and luminance simultaneously, used for complex color transformations and creative looks.
