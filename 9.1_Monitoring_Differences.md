# 9.1 Monitoring Differences: On-Set, Post-Production, and Theatrical Projection

## Theory

### Display Technology Hierarchy

**CRT References (Legacy but Critical Baseline):**
- Sony BVM-HX310 (final OLED CRT replacement, 2023+)
- True 2.4 gamma response (BT.1886 compliance)
- Infinite contrast ratio (0.0005 nits black level)
- No motion blur (instant pixel response)
- Reference standard for color grading decisions

**Professional OLED (Current Standard):**
- Sony BVM-HX310/HX260 (55" and 26" reference)
- LG C1/C2/C3 (calibrated for reference, budget option)
- Perfect blacks, infinite contrast
- Near-instant response time (0.1ms)
- Automatic Brightness Limiter (ABL) issues:
  - 10% window: 700-800 nits
  - 100% white: 150-200 nits (power limit)
- Panel uniformity critical (ΔE2000 <1.0 required)

**Professional LCD (Budget Alternative):**
- Sony Trimaster EL/P series
- Flanders Scientific CM series (CM250, CM310)
- LED backlit with local dimming
- Lower contrast (3000:1 typical, 5000:1 premium)
- Better bright-room stability
- Viewing angle critical (color shift >30° off-axis)

### Viewing Environment Physics

**Ambient Light Impact Formula:**
```
Perceived Black = Display Black + (Ambient lux × Screen Reflectivity)
Perceived Contrast = Display Peak / Perceived Black
```

**Critical Metrics by Environment:**
- **On-Set**: 15-30 lux ambient (highly variable, daylight interference)
- **Color Grading Suite**: <5 lux (ideal, pitch-black conditions)
- **Theatrical**: <0.1 lux after dark adaptation (15-20 min adaptation time)
- **Living Room**: 50-100 lux (typical home environment, streaming target)

**Surround Impact (Simultaneous Contrast):**
- Dark surround → pupil dilation → perceived +10-15% brightness
- Bias lighting critical: 65°C correlated, 10% peak white intensity
- Neutral gray walls (Munsell N8) prevent color casts
- Black velvet ceiling/floor reduces glare

### Calibration Standards

**SMPTE ST 2116-1 (OLED Reference Calibration):**
- Target luminance: 100 nits peak (Rec.709/P3 SDR)
- Black level: <0.0005 nits (OLED infinite)
- White point: D65 (CIE 1931 x=0.3127, y=0.3290)
- Gamma: 2.4 power law (Rec.709), 2.6 (DCI-P3 theatrical)
- Tracking tolerance: ±0.02 gamma across 10-90% range
- Color accuracy: ΔE2000 <1.0 after calibration
- Uniformity: ≥95% center-to-corner luminance

**DCI Specification (SMPTE RP 431-2):**
- Primary white: 48 cd/m² (14 fL, no more than 54 cd/m²)
- Sequential contrast: ≥2000:1 (ANSI contrast ≥100:1)
- Color gamut: DCI-P3 primaries (±0.001 CIE 1931)
- Uniformity: ≥85% center-to-edge (luminance and chromaticity)
- Chromaticity uniformity: Δu'v' <0.003
- White point: DCI white (x=0.3140, y=0.3510)

### Display Metamerism

**Metameric Failure Explanation:**
- Different spectral power distributions → same perceived color under reference
- Camera sensor response curves vs. human photopic vision
- Display primaries differences:
  - OLED (RGB emission spectra, narrow peaks)
  - LCD (broadband LED backlit + absorption filters)
  - CRT (phosphor emissions, unique spectral signature)

**Practical Impact:**
- Color matches on one display ≠ match on another
- Critical for skin tone reproduction (human vision most sensitive)
- Orange-red region particularly problematic (skin tone, foliage)
- Verify with spectroradiometer for critical work (not just colorimeter)

**Portables (Budget):**

- FeelWorld F6 (5" IPS, $200, basic monitoring)

**On-Set Monitoring Strategy:**

**1. Reference Display Setup:**
```bash
# Calibration workflow (monthly)
# 1. Warm-up display: 30 minutes minimum
# 2. Connect probe: X-Rite i1Display Pro, Klein K-10A
# 3. Software: CalMAN, LightSpace, TrueImage
# 4. Target: Rec.709 D65, 100 nit, gamma 2.4
# 5. 21-point grayscale: 0-100% in 5% steps
# 6. 7-point saturation: Rec.709 primaries, secondaries
# 7. Verify skin tone patch: ΔE2000 <1.0
# 8. Upload 1D LUT to display (hardware calibration)
# 9. Post-calibration verification (probe measurement)
```

**2. Exposure Monitoring:**
- **False Color**: 8-10 IRE target for middle gray (Rec.709)
- **Waveform**: 0-100% legal range, clipping indicator
- **Zebras**: 90-95% warning (preserve headroom for grading)
- **Histogram**: Overall distribution check (high-key vs. low-key)

**3. Color Monitoring:**
- **Vectorscope**: Skin tone line verification (flesh tone indicator)
- **CIE 1931 u'v'**: Gamut warning (Rec.709 vs. P3 vs. Rec.2020)
- **Parade**: RGB balance check (exposure bias, color cast)
- **Focus Peaking**: False color overlay, 80-100% red (sharp edges)

**On-Set LUT Workflow:**
```bash
# Three-tier LUT system
# Tier 1: Technical LUT (Log → Rec.709)
#          ARRI: LogC4-to-Rec709-v1.cube
#          Sony: S-Log3-to-Rec709-v2.cube
#          RED: Log3G10-to-Rec709-v3.cube

# Tier 2: Show LUT (Creative look from colorist)
#          ProjectName_ShowLUT_v1.2.cube
#          Applied on top of technical LUT

# Tier 3: Monitoring LUT (Combined technical + creative)
#          Generated by colorist: ShowLUT_Monitor_v1.cube
#          Single-file application, reduces errors

# Application order:
Camera RAW → CDL → Show LUT → Rec.709 Display
```

**Common On-Set Issues:**
- Direct sunlight → 500+ lux ambient, use hood/sunshade
- Wrong LUT version (v1.2 on-set, v1.5 in post → mismatch)
- Gamma mis-match (2.2 vs. 2.4 → 0.2 stop exposure error)
- Display drift (recalibrate monthly, on-set units quarterly)

```bash
# Hardware calibration (4-6 hours)
# 1. Warm-up display: 30 minutes
# 2. Clean screen: microfiber cloth (remove dust)
# 3. Ambient light: <5 lux (dark room)
# 4. Connect probe: Klein K-10A (spectroradiometer)
# 5. CalMAN Professional: Create project
# 6. Target settings:
#    - White point: D65 (x=0.3127, y=0.3290)
#    - Gamma: BT.1886 (2.4 power law)
#    - Luminance: 100 nit (10,000 cd/m²)
# 7. Grayscale optimization:
#    - 21-point grayscale (0-100% in 5% steps)
#    - Target ΔE2000 <1.0 each point
# 8. Color gamut optimization:
#    - Rec.709 primaries (R, G, B)
#    - Secondaries (C, M, Y)
#    - Target ΔE2000 <1.5
# 9. Skin tone verification:
#    - Caucasian skin tone patch
#    - Asian skin tone patch
#    - African American skin tone patch
#    - Target ΔE2000 <1.0
# 10. Upload 1D LUT to display (grayscale correction)
# 11. Upload 3D LUT (color gamut correction, if needed)
# 12. Post-calibration verification:
#     - Measure 9-point uniformity
#     - Check grayscale tracking
#     - Verify color accuracy
#     - Generate calibration report (PDF)
```

**Daily Verification (Before Grading, 5 minutes):**
```bash
# Quick check with LightIllusion LUT Box
# 1. Generate test pattern (internal signal)
# 2. Verify grayscale patches: 0%, 50%, 100%
#    - Measure with probe
#    - ΔE2000 <2.0 acceptable
# 3. Check color patches:
#    - Rec.709 primaries (R, G, B)
#    - Skin tone patch
# 4. Contrast ratio test:
#    - Black patch vs. room black
#    - Display black >10× darker than room
# 5. Ambient light check:
#    - Measure lux meter
#    - Target <5 lux
# 6. If any check fails:
#    - Full calibration required
#    - Backup display available (switchover)
```

**Grading Suite Environment Specifications:**
- **Walls**: Neutral gray (Munsell N8/18% gray recommended)
- **Floor**: Matte black or dark gray (avoid light reflection)
- **Ceiling**: Black velvet or matte black (absorb ceiling reflections)
- **Ambient light**: <5 lux (dark room, measure with lux meter)
- **Bias light**: 65°C correlated, 10% peak white, behind display
- **Viewing distance**: 1.5× picture height (THX recommendation)
- **Eye level**: Center of display at viewer eye level (±10°)

### Theatrical Projection Setup

**Digital Cinema Projector Types:**

**1. TIPO (Texas Instruments 3-Chip DLP):**
- Technology: 3-chip DLP (no rainbow effect, sequential color)
- Light source: Xenon lamp (legacy) or laser (modern)
- Resolution: 2K (2048×1080) or 4K (4096×2160) native
- Contrast: 2000:1 sequential, 100:1 ANSI
- Color: DCI-P3 native
- Manufacturers: Barco, Christie, Sony, NEC

**2. Laser Phosphor (Cost-Effective):**
- Technology: Blue laser → yellow phosphor → color wheel
- Cost: Lower than RGB laser (30-40% savings)
- Color gamut: Close to DCI-P3 (slightly limited in greens)
- Lifespan: 20,000+ hours (vs. 1,000-2,000 for xenon)
- Maintenance: Less frequent (no lamp changes)

**3. RGB Laser (Premium):**
- Technology: Red, green, blue lasers separately
- Color gamut: Beyond DCI-P3 (near Rec.2020 coverage)
- Contrast: 5000:1+ sequential (superior blacks)
- Lifespan: 30,000+ hours
- Cost: 2-3× laser phosphor
- Use case: Dolby Cinema, premium large format

**DCP Projection Calibration Workflow:**

**1. Screen Measurement (Physical):**
```bash
# Projector setup
# 1. Throw distance calculation:
#    Throw ratio = Distance / Screen Width
#    Example: 1.5:1 throw, 30ft wide screen → 45ft distance
# 2. Keystone correction:
#    - Vertical keystone (projector offset)
#    - Horizontal keystone (lens shift)
#    - Goal: 90° perpendicular to screen
# 3. Focus test:
#    - Siemens star pattern (focus chart)
#    - Sharpness corner-to-corner
#    - Verify with single-pixel test pattern
```

**2. Light Output Calibration:**
```bash
# Luminance measurement
# 1. Warm-up projector: 30 minutes
# 2. Target: 48 cd/m² white (14 fL) at screen
# 3. Measure with spectro-radiometer:
#    - Klein K-80 (portable, on-set)
#    - Jeti 1211 (laboratory grade)
#    - Photo Research PR-870
# 4. Adjust lamp power or laser output:
#    - Xenon: 1-3 kW (typical 2 kW)
#    - Laser: 20-70% power (depends on screen size)
# 5. Verify uniformity:
#    - 9-point measurement (center + 8 surrounding)
#    - ≥85% center-to-edge required
#    - ≥75% center-to-corner acceptable
```

**3. Color Calibration:**
```bash
# DCI-P3 calibration
# 1. Measure primaries:
#    - Red: x=0.680, y=0.320
#    - Green: x=0.265, y=0.690
#    - Blue: x=0.150, y=0.060
#    - Tolerance: ±0.001 CIE 1931
# 2. Verify white point:
#    - DCI white: x=0.3140, y=0.3510
#    - Green tint vs. D65 (intentional)
# 3. Check color tracking:
#    - Grayscale ramp: 0-100% in 10% steps
#    - Measure Δu'v' <0.003 across range
#    - Adjust CMS (Color Management System) if needed
# 4. Create calibration report:
#    - Save measurements (time-stamped)
#    - Baseline for future verification
```

**DCP Quality Check (Technical Check, 30-60 min):**
```bash
# Pre-screening verification
# 1. Load DCP into server:
#    - Doremi DCP-2000/3000
#    - Dolby DSS200/220
#    - Christie IMB (Integrated Media Block)
# 2. Play SMPTE test pattern:
#    - Color bars (primary/secondary colors)
#    - Grayscale ramp (0-100%)
#    - Focus pattern (Siemens star)
# 3. Verify geometry:
#    - Screen fill (no cropping)
#    - Aspect ratio (1.85:1 flat, 2.39:1 scope)
#    - Keystone correction (no distortion)
# 4. Check focus:
#    - Corner-to-corner sharpness
#    - Single-pixel visibility
# 5. Measure light output:
#    - Center screen: 48 cd/m² ± 10%
#    - Edges: ≥85% of center
# 6. Verify color:
#    - Primaries with probe
#    - White point measurement
# 7. Audio check:
#    - Channels 1-8 (7.1 surround)
#    - LFE (subwoofer) channel
#    - Level check: 85 dB SPL (reference)
# 8. Play first 5 min of feature:
#    - Visual check (overall appearance)
#    - Color timing verification
#    - Audio sync check
```

**Theatrical Environment Requirements:**
- **Ambient light**: <0.1 lux (pitch black after adaptation)
- **Dark adaptation**: 15-20 minutes for full scotopic vision
- **Screen reflectivity**: Matte white 1.0 gain standard (1.3-1.8 high-gain available)
- **Viewing angle**: ≤45° from center line (avoid color shift from hot-spotting)
- **Back row distance**: ≤1.5× screen height (avoid pixel visibility)

## Failure Modes

### Inconsistent Monitoring Across Pipeline

**Symptom:**
- On-set color decisions don't match post-production
- Dailies look different from final grade (colorist confused)
- Theatrical preview doesn't match color grading suite

**Root Causes:**
1. **Uncalibrated displays**: No regular calibration schedule
   - On-set monitors: 3-6 months without calibration
   - Post displays: 1-2 months drift (acceptable limit exceeded)
2. **Different calibration standards**:
   - Rec.709 2.2 gamma vs. 2.4 gamma (0.2 stop exposure difference)
   - D65 white point vs. 9300K (cool tint)
   - 100 nit vs. 80 nit target (brightness mismatch)
3. **Ambient light not controlled**:
   - On-set: 30 lux (daylight interference)
   - Suite: <5 lux (controlled dark)
   - Living room: 50 lux (consumer viewing)
4. **Different color spaces**:
   - Monitoring in P3 (theatrical) vs. grading in Rec.709 (SDR)
   - HDR monitoring (PQ) vs. SDR grade (Rec.709)
5. **LUT version mismatch**:
   - On-set LUT v1.2, colorist using v1.5 (evolved look)
   - CDL not applied in editorial (metadata lost)
   - Wrong LUT format (1D vs. 3D LUT)

**Detection Methods:**
- Regular calibration verification (probe measurement)
- Cross-check displays with known-good test patterns:
  - Skin tone patch (Caucasian, Asian, African American)
  - Color bars (Rec.709 primaries)
  - Grayscale ramp (gamma tracking)
- Maintain calibration log:
  - Date of calibration
  - Target settings (D65, gamma 2.4, 100 nit)
  - ΔE2000 results (before/after)
  - Probe used (Klein K-10A, i1Display Pro)
- Match ambient light conditions:
  - Lux meter measurement
  - Simulate viewing environments (on-set vs. suite)

**Prevention Strategies:**
- Standardize on Rec.709 D65 gamma 2.4 for on-set/dailies
- Calibrate all displays monthly (on-set quarterly minimum)
- Use spectroradiometer for critical matching:
  - Colorimeter-only insufficient (metameric failure)
  - Spectroradiometer measures full spectrum (380-780nm)
- Maintain LUT version control:
  - Include version in filename (ShowLUT_v1.2.cube)
  - Document in CDL/DLTM metadata
  - Git/tracked file for LUT repository
- Create "bridge LUT" between on-set and grading displays:
  - On-set LUT → grading display transformation
  - Verify with probe measurement
  - Document LUT chain for conform

### Wrong Environment (Ambient Light)

**Symptom:**
- Grades look too dark in living room (crushed shadows)
- Shadow detail lost on bright set (washed out)
- Color shifts when room lights change (perceived cast)

**Physics of Ambient Light Impact:**
```
Perceived Black Level = Display Black + (Ambient lux × Screen Reflectivity)
Perceived Contrast = Display Peak / Perceived Black

Example Calculation:
- Display black: 0.0005 nits (OLED)
- Screen reflectivity: 1% (matte coating)
- Ambient: 50 lux (living room)
- Perceived black: 0.0005 + (50 × 0.01) = 0.5005 nits
- Perceived contrast: 100 / 0.5005 = 200:1
- Native contrast: 100 / 0.0005 = 200,000:1
- Contrast loss: 99.9% (severe!)
```

**Detection:**
- Measure ambient light with lux meter (measure at display position)
- Verify perceived contrast with glare test:
  - Black screen (0% code value)
  - Turn on room lights
  - Measure perceived black (should remain <0.5 nits)
- Check shadow detail in graded content:
  - Is shadow detail invisible in bright room?
  - Are crushed blacks apparent (no detail)?
- Test grade on consumer OLED:
  - LG C3 in 50 lux environment
  - Compare to grading suite
  - Adjust grade if necessary

**Prevention:**
- Grade on reference display in dark room (<5 lux)
- Use "living room simulation" display for client review:
  - Consumer OLED (ABL present)
  - 200 nit target
  - 50 lux ambient
- Test grade on multiple displays:
  - Professional OLED (100 nit, dark room)
  - Consumer OLED (200 nit, 50 lux)
  - LCD (300 nit, 100 lux)
- Apply slight contrast boost for streaming:
  - +5-10% contrast (preserve highlight detail)
  - Lift shadows slightly (avoid crushing)
- Avoid crushing blacks:
  - Maintain 1-2% above true black
  - Preserve shadow detail for bright-room viewing
  - Use waveform monitor to verify

### Calibration Drift

**Symptom:**
- Color shift over time (red push, blue drift)
- Gamma tracking changes (mid-range too bright/dark)
- Display no longer matches probe measurements

**Causes of Display Drift:**

1. **OLED Aging**:
   - Blue OLED degrades faster than red/green (half-life 10,000 hours vs. 30,000 hours)
   - Color temperature shifts toward warmer (red push)
   - Panel non-uniformity (center vs. edges age differently)

2. **LED Backlight Aging** (LCD):
   - Backlight dims over time (50% brightness at 20,000 hours)
   - Color temperature shifts (LED phosphor degradation)
   - Local dimming zones age unevenly

3. **Temperature Effects** (OLED):
   - OLED efficiency drops with heat (sustained bright content)
   - ABL reduces brightness (power limit)
   - Heat causes temporary color shift (recovers when cool)

4. **Power Supply Drift**:
   - Voltage fluctuations affect brightness stability
   - Ripple in power supply (visible as flicker)
   - Aging capacitors (voltage sag)

5. **Panel Degradation**:
   - Burn-in (static images, logos, letterbox bars)
   - Image retention (temporary, recovers)
   - Pixel aging (differential usage)

**Detection:**
- Weekly calibration verification:
  - Probe measurement (Klein K-10A)
  - Check ΔE2000 tracking
- ΔE2000 tracking:
  - Plot over time (Excel/graph)
  - Replace display if >3.0 drift
  - Typical drift: 0.5-1.0 ΔE2000 per month
- Visual check:
  - Skin tone patch (known-good reference)
  - Compare to backup display
- Cross-check monthly:
  - Reference display vs. backup display
  - Verify both match probe measurement

**Prevention:**
- Calibrate monthly (professional environment)
  - Hardware calibration (direct to display)
  - Avoid GPU LUTs (less accurate)
- Use OLED features to prevent burn-in:
  - Pixel shift (move image 1-2 pixels)
  - Screen move (periodic shift)
  - Pixel refresher (full-screen cycle)
- Limit sustained brightness:
  - Avoid 100 nit white >5 minutes
  - Use full-screen content
  - Reduce peak brightness for static images
- Replace displays at end-of-life:
  - OLED: 20,000 hours (half-life)
  - LCD: 30,000-50,000 hours (backlight)
  - Maintain backup display (switchover during calibration)
- Maintain calibration log:
  - Date/time of calibration
  - ΔE2000 results (before/after)
  - Drift trend (plot over time)
  - Replacement schedule (based on usage)

### Projection System Mismatch

**Symptom:**
- DCP color looks different in different theaters
- Dark scenes crushed in some venues, fine in others
- Color grading suite match achieved but theatrical preview wrong

**Causes:**

1. **Screen Gain Variations**:
   - 1.0 gain (matte white): Uniform, low hotspot
   - 1.3-1.8 gain (high-gain): Brighter, hot-spot in center
   - Retro-reflective (silver screen): 3D only, narrow viewing angle

2. **Projector Age/Maintenance**:
   - Xenon lamp dimming: 50% brightness at 1,000 hours
   - Laser: Minimal degradation (<5% at 10,000 hours)
   - Dust on optics: Reduces contrast, causes flare

3. **Calibration Differences**:
   - 48 cd/m² target (DCI standard)
   - 54 cd/m² maximum allowed (12.5% brighter)
   - Different calibrators (Klein vs. Jeti)

4. **Ambient Light Issues**:
   - Exit signs (red/orange glow)
   - Aisle lights (step lighting)
   - Booth light leak (projection port)
   - Wall reflections (light-colored walls)

5. **Projection Throw Issues**:
   - Short throw: Uniformity problems at edges
   - Long throw: Focus issues corner-to-corner
   - Keystoned: Geometric distortion, color shift

**Detection:**
- Request calibration report from venue:
  - Date of last calibration
  - Luminance measurement (48 cd/m²)
  - Color gamut verification (DCI-P3)
- Bring portable probe to screening:
  - Klein K-10A (battery-powered)
  - Measure white point, luminance
  - Compare to calibration report
- Visual check:
  - SMPTE bars in DCP (evaluate color/contrast)
  - Skin tone reference (known-good clip)
  - Dark scene test (crushed blacks?)

**Prevention:**
- Create theatrical DCP with conservative contrast:
  - Avoid crushing blacks
  - Maintain shadow detail
  - Test on aging projector (worst-case)
- Test screening at mixing stage:
  - Simulated theatrical environment
  - DCI-compliant projector
  - Verify color timing
- Request "flat" screen (1.0 gain) for critical preview:
  - Avoid high-gain screens
  - Hot-spotting causes color shift
- Deliver DCP with slight brightness boost:
  - +3-5% luminance (for old lamps)
  - Compensates for lamp dimming
  - Verify on new projector (not too bright)
- Avoid relying on specular highlights:
  - May clip on older projectors
  - Maintain detail in highlights
  - Test on multiple projectors

## Mini Glossary

**Viewing Environment:**
Surrounding conditions affecting display perception: ambient light level, wall color, viewing distance, bias lighting. Critical for consistent color appearance across different locations. Measured in lux (ambient), Munsell N8 (neutral gray), distance in picture heights (1.5× recommended).

**Projection:**
Theatrical display using light source (lamp/laser) illuminating reflective screen. DCI-compliant projection calibrated to 48 cd/m² (14 fL), DCI-P3 color gamut, 2K/4K resolution. Requires dark room (<0.1 lux ambient) and screen gain matching (1.0 matte standard).

**Reference Display:**
Professionally calibrated monitor used for critical color evaluation. Rec.709 D65 gamma 2.4, 100 nit peak, ΔE2000 <1.0 color accuracy. Sony BVM-HX310, Flanders Scientific CM250. Hardware calibrated monthly, verified daily before grading.

**Ambient Light:**
Room light incident on display surface. Reduces perceived contrast: Ambient + Display Black = Perceived Black. Critical to control (<5 lux for grading). Measured in lux (lux meter), impacts black level and perceived saturation.

**Calibration Consistency:**
Regular measurement and adjustment to maintain display adherence to standards. Monthly hardware calibration (probe measurement), daily verification (5 min check). Calibrated to D65 white point (x=0.3127, y=0.3290), gamma 2.4, 100 nit peak luminance.

**Contrast Ratio (Sequential):**
Peak white divided by black level (measured separately, not simultaneously). OLED: ∞:1 theoretical, 200,000:1 measured. LCD: 3000:1-5000:1. Critical metric for evaluating display capability, especially for dark scene reproduction.

**Contrast Ratio (ANSI):**
White and black measured simultaneously (checkerboard pattern). Lower than sequential due to internal scattering, light leakage. LCD: 500:1-1000:1, DLP: 200:1-500:1. More real-world metric than sequential contrast.

**Gamma:**
Power function relating input code value to output luminance. Rec.709: 2.4 (segmented with linear segment near black). DCI-P3: 2.6 gamma. Critical for perceived brightness and mid-tone reproduction. Deviations >±0.1 visible as brightness shift.

**White Point:**
Chromaticity coordinates of white (D65: x=0.3127, y=0.3290 for Rec.709). Determines overall color temperature (6500K for D65). Critical for skin tone reproduction, overall color balance. DCI white: x=0.3140, y=0.3510 (slightly green).

**Bias Light:**
65°C correlated light behind display, 10% peak white intensity. Maintains pupil size (prevents dilation in dark room), reduces eye strain, improves perceived contrast ratio. Position: 20-30cm behind display edges, diffuse lighting.

**ABL (Automatic Brightness Limiter):**
OLED power limit reducing peak brightness with large bright areas. 10% window: 700-800 nit, 100% white: 150-200 nit (varies by model). Critical limitation for OLED displays, affects HDR grading (avoid sustained full-screen white).

**Uniformity:**
Consistency of brightness and color across display area. ≥85% center-to-edge acceptable, ≥95% for reference displays. Critical for color grading (avoid hot-spotting). Measured with 9-point pattern (center + edges/corners).

**Metamerism:**
Different spectral power distributions perceived as same color under reference illuminant. Critical issue: camera sensor response vs. human vision vs. display primaries. Causes color matches on one display to not match on another. Verify with spectroradiometer.

**Spectroradiometer:**
Instrument measuring spectral power distribution (380-780nm). Reference for display calibration (measures full spectrum). Klein K-10A ($8K), Jeti 1211 ($15K), Photo Research PR-870 ($20K). Required for critical matching, colorimeter-only insufficient.

**Colorimeter:**
Filter-based instrument measuring XYZ tristimulus values (faster than spectroradiometer, less accurate). Tristimulus sensor with XYZ filters. X-Rite i1Display Pro ($300), Datacolor SpyderX ($270). Good for calibration verification, not critical matching.

**ΔE2000 (Delta E 2000):**
Color difference metric (perceptual uniformity). ΔE2000 <1.0: imperceptible, 1-2: noticeable (just noticeable difference), >3: objectionable. Use for calibration verification, tracking display drift over time. Measured with probe (spectroradiometer/colorimeter).
