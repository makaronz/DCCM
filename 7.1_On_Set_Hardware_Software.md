# 7.1 On-Set Hardware and Software

## Theory

### DIT Cart Architecture

The [DIT cart] [Digital Imaging Technician workstation] serves as the central hub for on-set color management, data management, and quality control. Modern DIT cart architecture follows a modular design philosophy that prioritizes signal integrity, color accuracy, and operational efficiency.

**Signal Flow Architecture:**
- Camera output (SDI/HDMI/fiber) → Input processing → Color management → Distribution
- Primary path always maintains highest quality (12-bit/4:4:4 when available)
- Secondary feeds for video village may apply compression for bandwidth optimization

**Processing Chain:**
1. [Signal processing] [Video signal manipulation and optimization] begins at camera output
2. Color space conversion occurs before any compression
3. LUT/CDL application in dedicated hardware for minimal latency
4. Distribution amplifier feeds multiple destinations simultaneously

### Color Management Chain

The on-set color management chain must maintain precision from capture to display:

**Input Stage:**
- Camera native color space → Input device (capture card/SDI input)
- Preserve camera metadata through the chain
- Support for RAW, Log, and linear signals

**Processing Stage:**
- Real-time color space transforms (CST)
- LUT application (technical and creative)
- CDL parameter application
- HDR/SDR conversion when needed

**Output Stage:**
- Multiple graded outputs for different stakeholders
- Reference-grade monitoring for critical decisions
- Consumer-grade monitoring for client review (with appropriate limitations)

## Practice

### Hardware Selection

**Monitors:**

*Reference-Grade Options (2024-2025):*
- **Sony BVM-HX310** (31.5" OLED): The current gold standard for HDR/SDR monitoring. 4096x2160, supports HDR/PQ, HLG, and SDR simultaneously. TR > 1,000,000:1, peak luminance 1000 nits sustained.
- **Sony PVM-X2400** (24" OLED): Compact reference monitor with same OLED panel technology. Ideal for tight DIT carts.
- **Dolby Vision Reference Monitor**: Expensive but definitive for Dolby-certified workflows.
- **Flanders Scientific XM311K** (31" 4K LCD): High-end LCD alternative, 4000 nits peak, excellent for HDR monitoring. More affordable than OLED with similar accuracy.
- **Flanders Scientific DM250** (24.5" 4K LCD): Workhorse monitor, supports 12G-SDI, HDR, and automatic calibration.

*Production-Grade Options:*
- **SmallHD Cine 24** and **Cine 13**: Good color accuracy, built-in scopes, portable.
- **SmallHD OLED series**: OLED panels at lower price points, suitable for video village.
- **Atomos Sumo 19"**: Large format, affordable, supports HDR monitoring.
- **Atomos Shinobi/Sumo**: Good for director's monitors, not reference grade.

**Scopes and Waveform Monitors:**

*Dedicated Hardware:*
- **Leader LV5600** / **LV7600**: Industry standard for waveform/vectorscope monitoring. Essential for broadcast compliance.
- **Tektronix WFM7200** / **WFM8300**: High-end options with comprehensive signal analysis.
- **Blackmagic SmartScope Duo 4K**: Affordable dual-scope solution, 8-inch displays.

*Software-Based:*
- **DaVinci Resolve Studio scopes**: Excellent when used with calibrated reference display.
- **ScopeBox**: macOS software solution for waveform monitoring.
- **Pomfort Livegrade Pro**: Built-in scopes optimized for on-set workflows.

**LUT Boxes:**

*Production-Tested Options:*
- **Teradek COLR**: Wireless LUT box with CDL support, integrates with Bolt transmitters. 3D LUT support, 1 frame latency, SDI in/out.
- **Flanders Scientific BoxIO**: Premium option, supports 4K, HDR, dual-channel processing. Can be controlled via software. Essential for critical color work.
- **AJA FS-HDR**: Frame sync + HDR converter + LUT box. Supports 12G-SDI, HDR/SDR conversion. Expensive but versatile.
- **Blackmagic Teranex Mini SDI to HDMI 8K HDR**: Budget-friendly option, supports up to 8K, HDR processing.
- **Cobalt 9215**: Broadcast-grade LUT box with frame sync.

**Processors and Converters:**

*Signal Management:*
- **AJA Kumo 6464**: 12G-SDI router, 64x64, essential for complex setups.
- **Blackmisdesign Videohub**: Cost-effective routing, Smart Videohub series widely used.
- **Decimator MD-HX**: Down/cross-converter, frame sync, essential for mismatched signals.

**Colorimeters and Calibration:**

*Professional Grade:*
- **Klein K10-A**: Industry standard colorimeter for on-set calibration.
- **X-Rite i1Display Pro Plus**: Consumer-friendly option, good for field calibration.
- **Photo Research PR-740/745/788**: Spectroradiometers, lab-grade accuracy, expensive.

### DIT Cart Buildout

**Essential Components:**

1. **Computer System**
   - MacBook Pro M3 Max (16" recommended) or Mac Studio for power
   - 32GB RAM minimum, 64GB+ recommended
   - Fast SSD storage (2TB+ internal)
   - Multiple Thunderbolt 4 ports
   - eGPU support for Resolve (optional)

2. **Power Distribution**
   - Dedicated power circuits (20A minimum)
   - UPS ( uninterruptible power supply ) for brownout protection
   - Clean power with surge suppression
   - Cable management and strain relief

3. **Monitoring**
   - Primary reference monitor (graded image)
   - Technical monitor (waveform/vectorscope)
   - Client monitor (video village feed)
   - Camera view monitor

4. **Storage**
   - Fast RAID for live processing (8TB+ minimum)
   - SSD docks for camera media offload
   - Backup drives (3-2-1 rule)
   - LTO drive for archival (optional)

5. **Cabling and Infrastructure**
   - 12G-SDI copper cables (BNC, quality connectors)
   - Fiber runs for long distances (>100')
   - HDMI for consumer displays
   - Cable management system

6. **Network**
   - 10GbE switch for large file transfers
   - Gigabit Ethernet for basic connectivity
   - Wireless access point for remote viewing

## Failure Modes

### Bandwidth Issues

**Symptoms:**
- Frame drops during monitoring
- Compression artifacts suddenly appearing
- Audio/video sync drift
- Frozen or stuttering video

**Causes:**
- Insufficient storage throughput
- Router/port bandwidth exceeded
- Cable length exceeding signal integrity limits
- Too many devices on same network segment

**Mitigation:**
- Calculate required bandwidth with 30% headroom
- Use 12G-SDI for 4K signals
- Employ fiber for runs >100'
- Monitor network traffic and switch capacity
- Test signal path before critical takes

### Wrong Color Space

**Symptoms:**
- Oversaturated colors
- Incorrect gamma appearance
- Color shifts that don't match reference
- Client complaints about "wrong look"

**Causes:**
- Wrong LUT applied
- Color space mismatch in signal chain
- Monitor not calibrated to target
- Incorrect CDL values

**Mitigation:**
- Document color pipeline from camera to display
- Verify LUT order and application
- Calibrate monitors daily for critical work
- Use scopes to verify signal integrity
- Maintain written color workflow documentation

### Hardware Failures

**Symptoms:**
- No video signal
- Intermittent signal dropouts
- Color shifts on one output only
- Fan noise or thermal shutdown

**Causes:**
- Cable failure (BNC connector damage)
- Power supply failure
- Overheating equipment
- Software crashes

**Mitigation:**
- Critical path redundancy (backup cables, backup LUT box)
- Temperature monitoring on cart
- Regular cable testing/replacement
- Auto-save configurations frequently
- Keep spare critical components on hand

## Mini Glossary

- **[DIT cart]** (Digital Imaging Technician cart): Mobile workstation housing color management, data management, and quality control equipment for on-set workflows.

- **[Signal processing]**: Manipulation and optimization of video signals, including color space conversion, format conversion, and quality enhancement.

- **[Scopes]**: Technical monitoring tools (waveform monitor, vectorscope, histogram) for analyzing video signal characteristics and ensuring technical compliance.

- **[Waveform monitor]**: Display device showing luminance/brightness values over time, used to verify exposure levels and signal legality.

- **[Vectorscope]**: Display device showing color information (hue and saturation) in a circular format, used to verify color accuracy and legal color ranges.

- **[LUT box]**: Hardware device that applies Look Up Tables (LUTs) to video signals in real-time, enabling consistent color monitoring across multiple displays.
