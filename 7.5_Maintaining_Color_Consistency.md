# 7.5 Maintaining Color Consistency

## Theory

### Color Consistency Across Dimensions

[Color consistency] [Maintenance of uniform color appearance across time, space, and equipment] is fundamental to professional image quality. Inconsistencies break viewer immersion and signal technical incompetence:

**Temporal Consistency:**
- Across multiple shooting days
- Throughout single day (lighting changes)
- Across takes of same scene
- From pre-production through final delivery

**Spatial Consistency:**
- Across different cameras (A/B camera, multi-cam)
- Across different lenses
- Across different lighting conditions
- Across different locations

**Device Consistency:**
- Across on-set monitors
- Between on-set and post-production
- Across delivery platforms
- Between reference and consumer displays

### Camera Matching Fundamentals

Different cameras reproduce color differently due to:

**Sensor Characteristics:**
- Spectral sensitivity variations
- Color filter array (CFA) designs
- Infrared filtering characteristics
- Noise patterns and processing

**Internal Processing:**
- Demosaicing algorithms
- Noise reduction strategies
- Sharpening and detail enhancement
- Color science implementation

**Metadata Considerations:**
- White balance metadata preservation
- ISO/gain settings
- Color mode selections
- Look/profile applications

### Metadata and Continuity

[Metadata] [Data embedded in or accompanying video files describing technical parameters] is the backbone of color consistency:

**Essential Color Metadata:**
- Camera make/model
- Recording codec and color space
- White balance settings
- ISO/gain and exposure index
- Applied looks or LUTs
- CDL values if applied on-set

**Continuity Documentation:**
- Scene-by-scene color notes
- Lens characteristics
- Lighting conditions
- Time of day/weather
- Color reference frames

## Practice

### Matching Cameras

**Pre-Production Camera Matching:**

1. **Select Compatible Cameras**
   - Same make/model if possible (ARRI Alexa, RED Komodo)
   - Similar sensor size and technology
   - Compatible color science
   - Matching recording formats

2. **Establish Matching Protocol**
   - Choose reference camera (typically A-camera)
   - Create matching LUTs for each camera
   - Test in variety of lighting conditions
   - Document settings for each camera

3. **Technical Matching Steps**
   - Match exposure (same T-stop, same lighting)
   - Match white balance (same Kelvin/tint)
   - Match dynamic range settings
   - Apply matching LUTs or color corrections
   - Verify with skin tone charts

4. **Creative Matching**
   - Adjust for subtle differences
   - Focus on skin tones (most critical)
   - Check shadow and highlight rolloff
   - Test with actual talent if possible

**Camera Matching Software:**

*DaVinci Resolve Studio:*
- Primary tool for camera matching
- Color page with node-based corrections
- Qualifier for selective adjustments
- Powerful matching features
- Save stills for reference

*Pomfort Livegrade Pro:*
- Real-time camera matching on set
- Side-by-side camera comparison
- Shot library for matching references
- Direct LUT creation

*Adobe Premiere Pro:*
- Lumetri Color panel
- Comparison view
- Good for offline editing matching

**Practical Matching Workflow:**

```
Reference Camera → Match Camera
     ↓                 ↓
  Technical LUT    Matching LUT
     ↓                 ↓
  Scene-Specific  Scene-Specific
  CDL Applied    CDL Applied
     ↓                 ↓
  Final Grade ← Matched Grade
```

### White Balance Consistency

**White Balance Best Practices:**

1. **On-Set Procedures**
   - Use professional color temperature meters (Sekonic, Minolta)
   - Measure dominant light source
   - Set white balance manually (avoid auto white balance)
   - Lock white balance once set
   - Re-measure when lighting changes significantly

2. **Mixed Lighting Situations**
   - Choose dominant light source for white balance
   - Use CTB/CTO gels to match light sources
   - Consider practical lamps (may need color correction)
   - Test with skin tones under actual conditions
   - Document gel combinations for continuity

3. **Tint Adjustments**
   - Compensate for green/magenta shifts (fluorescent, LED)
   - Use minus green or plus green gels as needed
   - Adjust tint in camera (magenta/green axis)
   - Verify with skin tone charts

4. **Daylight Variations**
   - Early morning: warmer (lower Kelvin)
   - Midday: cooler (higher Kelvin)
   - Late afternoon: warmer
   - Overcast: cooler than direct sun
   - Re-white balance when quality of light changes

**White Balance Documentation:**

- Log Kelvin and tint values per shot
- Note time of day and weather
- Document gel combinations used
- Photograph color charts for reference
- Save white balance presets per scene

### Look Maintenance

**Look Development Process:**

1. **Establish Base Look**
   - Work with Director and DP
   - Create technical LUT for monitoring
   - Develop creative look LUT
   - Test on variety of footage
   - Get approval on reference frames

2. **Document Look Parameters**
   - Export LUTs (technical and creative)
   - Create CDL values for each scene/shot
   - Save stills from reference shots
   - Document grading decisions
   - Create look book for continuity

3. **Maintain Look Across Production**
   - Apply same technical LUT to all cameras
   - Match creative look across cameras
   - Test look in different lighting conditions
   - Adjust for scene-specific requirements
   - Keep DIT informed of look changes

4. **Communicate with Post**
   - Deliver all LUTs and CDLs
   - Provide reference frames
   - Document creative intent
   - Schedule color review if needed
   - Be available for questions

**Look Consistency Challenges:**

- *Lighting changes*: Daylight varies, different locations
- *Lens differences*: Varying color transmission
- *Camera aging*: Sensors and filters age differently
- *Monitor drift*: Calibration changes over time

**Solutions:**
- Regular monitor calibration
- Consistent LUT application
- Frequent reference frame checks
- Communication with all departments
- Flexibility within established look

### Metadata Management

**Critical Color Metadata:**

*Camera Metadata:*
- Make, model, serial number
- Recording codec and color space
- ISO/EI and gain settings
- White balance (Kelvin and tint)
- Shutter angle and frame rate
- Lens information

*Color Grading Metadata:*
- Applied LUTs and CDLs
- Grading decisions (node structure)
- Keyframe information
- Shot-to-shot matching data
- Reference frame links

*Production Metadata:*
- Scene/take information
- Timecode
- Date and location
- Weather and time of day
- Lighting conditions

**Metadata Preservation:**

1. **On-Set Capture**
   - Use proper offload software (Silverstack, Hedge)
   - Verify metadata integrity
   - Backup with checksums
   - Maintain original camera metadata
   - Avoid re-wrapping if possible

2. **Post-Production Transfer**
   - Use XML/EDL for edit decisions
   - Preserve CDL data through pipeline
   - Maintain LUT associations
   - Document any metadata transformations
   - Use AAF for complex projects

3. **Long-term Archival**
   - Keep original camera files
   - Archive LUTs and CDLs separately
   - Document color workflow
   - Include metadata reports
   - Consider open formats (MXF, DPX)

## Failure Modes

### Drifting Colors

**Symptoms:**
- Colors gradually change throughout shooting day
- Skin tones appear different in afternoon vs morning
- Overall cast develops (warm or cool)
- Continuity errors visible in footage

**Causes:**
- Daylight color temperature changes
- Lighting units aging or changing
- Camera sensor temperature changes
- Monitor drift without recalibration
- Inconsistent LUT application

**Mitigation:**
- Regular white balance checks (hourly minimum)
- Monitor calibration daily for critical work
- Use consistent lighting whenever possible
- Apply gels to maintain color temperature
- Reference frame checks every few setups
- Document time-of-day lighting changes

### Unmatched Cameras

**Symptoms:**
- Obvious color differences between cameras
- Skin tones different on A vs B camera
- Shadow/highlight behavior differs
- Cut between cameras jarring

**Causes:**
- Different camera makes/models without matching
- Different lenses with different coatings
- Inconsistent white balance settings
- Different ISO/gain settings
- Mismatched LUTs or color corrections

**Mitigation:**
- Test cameras together before production
- Create matching LUTs for each camera
- Use same lenses if possible
- Match exposure and white balance precisely
- Apply consistent CDLs to all cameras
- Test with skin tones extensively
- Have DIT monitor multi-cam setups

### Lost Metadata

**Symptoms:**
- Unknown camera settings for footage
- Missing white balance information
- No record of applied LUTs/CDLs
- Inability to reproduce color decisions
- Post-production workflow disrupted

**Causes:**
- Improper offload procedures
- Re-wrapping files without metadata preservation
- Using wrong software or settings
- Hard drive corruption
- Human error in documentation

**Mitigation:**
- Use professional offload software (Silverstack)
- Verify metadata integrity after offload
- Backup with checksum verification
- Maintain written logs as backup
- Test restore procedures before critical work
- Keep original camera files untouched
- Document everything (double documentation)

### Version Control Issues

**Symptoms:**
- Multiple versions of same LUT/CDL exist
- Uncertainty about which is current
- Wrong version applied in post
- Confusion about approved looks

**Causes:**
- Poor naming conventions
- Inadequate version tracking
- Multiple independent creators
- Communication breakdown between set and post

**Mitigation:**
- Establish clear naming convention at start
- Use version control (Git, dedicated server)
- Single point of approval for LUTs/CDLs
- Regular communication with post team
- Destroy/obsolete old versions clearly
- Create "locked" or "final" versions
- Document changes between versions

## Mini Glossary

- **[Color consistency]**: Maintenance of uniform color appearance across time, space, and equipment throughout production and post-production.

- **[Camera matching]**: Process of adjusting multiple cameras to produce consistent color reproduction, involving technical and creative adjustments.

- **[White balance]**: Camera adjustment ensuring accurate color reproduction under different light sources, specified in Kelvin (color temperature) and tint (green-magenta axis).

- **[Look]**: Distinctive color treatment or visual style applied to footage, developed collaboratively between Director, DP, and DIT, maintained throughout production.

- **[Metadata]**: Data embedded in or accompanying video files describing technical parameters (camera settings, color information, shot details) essential for color management.

- **[Continuity]**: Consistency of visual elements (including color) across shots and scenes, critical for viewer immersion and narrative flow.

- **[Reference frame]**: Representative image from approved take, used for color matching, continuity verification, and communication with post-production.

- **[Color chart]**: Standardized test target with known color values, used for calibration, white balance verification, and color consistency checking.

- **[Kelvin]**: Unit of measurement for color temperature, lower values (3200K) appear warmer (orange), higher values (5600K+) appear cooler (blue).

- **[Tint]**: Color balance adjustment on green-magenta axis, compensates for color casts from fluorescent or LED lighting, measured in plus/minus green.
