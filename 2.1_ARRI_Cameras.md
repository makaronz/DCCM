# 2.1 ARRI Cameras (ALEXA 35, ALEXA LF, ALEXA 26F)

## Theory: ARRI Color Science Philosophy

### ARRI Color Science Foundation

**ARRI Color Science (ACS)** [ARRI's proprietary image processing pipeline designed to produce cinematic images with natural skin tones and pleasing highlight roll-off] emphasizes visual quality over technical specifications. Three core principles:

1. **Skin tone optimization**: AWG (ARRI Wide Gamut) specifically tuned for accurate Caucasian, Asian, and African skin tones
2. **Highlight preservation**: LogC encoding provides smooth roll-off preventing harsh clipping
3. **Shadow quality**: Large photosites (4.6µm on ALEXA 35) deliver clean shadow detail

**ALVF-2** [ARRI Linear Variable Filter system 2nd generation: mechanical ND filtration system integrated into sensor module] enables exposure control without ISO changes, preserving color fidelity across exposure settings.

### ALEV IV Sensor Architecture

**ALEV IV** [ARRI's 4th generation ALEV sensor in ALEXA 35 with 4.6K Super 35 format] specifications:
- Dimensions: 26.14mm × 13.76mm (Super 35)
- Photosite size: 4.6µm × 4.6µm (largest in class)
- Resolution: 4608 × 2592 (4.6K)
- Base ISO: 800 (EI 800)
- Dynamic range: 17 stops (claimed, measured 16.5 stops)
- Quantum efficiency: >70% (peak, 550nm)

**Noise performance**:
- Read noise: 2.8e- at base ISO
- Full well capacity: 88,000e-
- Dynamic range: 20 * log10(88000/2.8) ≈ 149dB → 17 stops
- SNR at 18% gray: 57dB (excellent)

### LogC4 Encoding

**LogC4** [ARRI's 4th generation logarithmic encoding introduced with ALEXA 35 in 2023] replaces LogC3:

$$
V = 717 \cdot \log_{10}(5.555555 \cdot L^{(1/4.4)} + 0.016779) + 709
$$

**Key innovations**:
1. **Power-law preprocessing**: $L^{(1/4.4)}$ before log provides better highlight linearity
2. **Single curve**: All 17 stops in one curve (no EI-specific variations)
3. **Optimized code allocation**: More values in shadows, fewer in highlights
4. **Backward compatibility**: LogC3 footage grades similarly with proper IDT

**Code value mapping** (normalized linear → 10-bit):
- Noise floor (0%) → CV 95
- 18% gray → CV 599
- 100% reflectance → CV 805
- +6 stops above 18% → CV 928
- Clip point → CV 1023

**Shadow SNR improvement**: LogC4 allocates 504 code values to shadows (CV 95-599) vs LogC3's 293 values. Result: 2.4dB better shadow SNR.

### REVEAL Color Engine

**REVEAL** [ARRI's next-generation color science engine introduced with ALEXA 35, version 4+ as of 2024] encompasses:

1. **Spectral characterization**: ALEV IV's spectral response meticulously measured and modeled
2. **Illuminant-aware processing**: Adapts rendering based on scene illuminant metadata
3. **Tone mapping**: Scene-referred to display-referred transformation
4. **Look management**: ARRI Look Library integration

**REVEAL v4 vs v3** (pre-2023):
- Improved highlight handling (less color crosstalk)
- Better shadow saturation preservation
- Enhanced skin tone rendering across ethnicities
- More accurate white balance transformations

**Critical**: REVEAL v4 required for LogC4 decoding. Older software (pre-2023) applies wrong transform, causing:
- Magenta cast in shadows (incorrect green channel gain)
- Wrong contrast (wrong gamma assumption)
- Color shifts (incorrect matrix)

### ARRI Wide Gamut (AWG)

**ARRI Wide Gamut** [ARRI's native color space, slightly larger than P3, optimized for cinema production]:

**Primary chromaticities** (approximate, exact values proprietary):
- Red: (0.68, 0.32) - similar to P3
- Green: (0.27, 0.68) - slightly greener than P3
- Blue: (0.15, 0.06) - similar to P3
- White: D65 (0.3127, 0.3290)

**Gamut coverage**:
- vs DCI-P3: ~102% (slightly larger)
- vs Rec.2020: ~70% (smaller, typical for camera-native gamuts)
- vs Pointer's gamut: ~98% of real surface colors

**Skin tone optimization**: AWG specifically tuned to prevent skin tone hue shifts common in wide gamuts. Critical for narrative work where skin tone accuracy matters.

## Practice: Exposure, White Balance, Look Library

### Exposure Index (EI) Workflow

**EI [Exposure Index: ISO-like setting for exposure metering, distinct from sensor gain]** on ARRI cameras:

**Traditional ISO vs ARRI EI**:
- **ISO** (technically): Signal gain applied after sensor
- **EI** (ARRI): Metadata parameter adjusting monitoring LUT, not recorded data

**LogC3 EI workflow**:
- Set EI to desired exposure index (EI 160-3200)
- Camera records at base ISO (800)
- EI change adjusts monitoring LUT (appears brighter/darker)
- Highlight headroom preserved regardless of EI

**LogC4 simplification**:
- Single curve covers all exposure scenarios
- EI adjusts monitoring LUT only
- No "EI curve" variations (unlike LogC3)
- Recommended EI: 800 (base), 1600 (high-key), 400 (low-key)

**Exposure strategy**:
1. **ETTR** (Expose To The Right): Maximize signal without clipping
2. **False color**: Use on-set monitor to verify exposure
3. **Skin tones**: Target CV 550-650 for LogC4 (middle-gray region)
4. **Highlight headroom**: Reserve 2-3 stops above key face

**Practical EI settings**:
- **EI 800**: Base, optimal SNR, most common
- **EI 1600**: Brighter monitoring, 1 stop less highlight headroom
- **EI 400**: Darker monitoring, 1 stop more highlight headroom
- **EI 3200**: Low-light situations, 2 stops less highlight headroom

### White Balance Workflow

**AWB** [Auto White Balance]: NOT recommended for narrative work. Use manual white balance for consistency.

**Manual white balance procedure**:
1. Measure scene illuminant (colorimeter or gray card)
2. Set Kelvin (2000-10000K) and tint (-20 to +20)
3. Verify with skin tones on monitor
4. Lock for duration of scene/lighting setup

**Common CCT values**:
- Tungsten (3200K): Incandescent, practical lights
- Daylight (5600K): Overcast sky, HMI
- Mixed (4000-4500K): Fluorescent, LED mixed sources
- Xenon (6000K approx): Digital cinema projection

**Tint adjustment**:
- Negative tint: Green compensation (magenta scene)
- Positive tint: Magenta compensation (green scene)
- Typical range: ±5 units from correct

**White balance metadata**:
- Embedded in ARRIRAW (required for LogC decoding)
- Incorrect metadata = magenta/green cast in post
- Always verify on set with calibrated monitor

### ARRI Look Library

**ARRI Look Library** [predefined 3D LUTs designed by ARRI for specific creative looks, compatible with all ALEXA cameras] includes:

**Basic looks**:
- **Video**: Rec.709-like contrast and saturation
- **LogC**: Passthrough (no look applied)
- **709**: Rec.709 broadcast standard

**Creative looks** (2024):
- **ARRI DNA**: Subtle contrast boost, skin tone warmth
- **Classic Film**: Highlight roll-off mimicking 35mm film
- **Florian**: High contrast, teal/orange (popular commercial look)
- **Kingsbury**: Low contrast, desaturated (indie film look)
- **Tokyo**: Desaturated shadows, warm highlights

**Look workflow**:
1. **On-set**: Load desired look into monitor for reference
2. **Dailies**: Apply look in dailies generation for client preview
3. **Grading**: Import look as starting point, not final look
4. **Delivery**: Never bake look into master (always preserve LogC)

**Look implementation**:
- 1D LUT: Tone curve adjustment
- 3D LUT: Color saturation and hue adjustment
- Shader LUT: Advanced color transformation (ARRI-specific)

**Custom look creation**:
1. Start from LogC4 footage
2. Create grade in DaVinci Resolve, Baselight, etc.
3. Export as 3D LUT (33×33×33 minimum)
4. Upload to camera via SD card
5. Apply on-set for monitoring consistency

## Failure Modes

### LogC3 vs LogC4 Confusion

**Symptom**:
- LogC4 footage appears wrong contrast/color in older software
- Magenta cast in shadows
- Incorrect skin tone reproduction

**Root cause**:
- Pre-2023 software lacks REVEAL v4 support
- Applies LogC3 IDT to LogC4 footage
- Different code value allocation causes wrong decoding

**Detection**:
- Check software version: REVEAL v4 required (DaVinci Resolve 18.1+, Baselight 5.2+)
- Check metadata: "LogC4" in clip properties
- Visual check: Footage looks flat/magenta vs expected LogC appearance

**Solution**:
1. Update software to REVEAL v4 compatible version
2. Apply correct LogC4 IDT
3. Verify with skin tones
4. Re-render dailies with correct transform

**Prevention**:
- Document camera settings in camera report (LogC4 noted)
- Embed metadata in file names (e.g., SC001_001_LOGC4)
- Test workflow before principal photography
- Verify dailies look correct on set

### REVEAL Metadata Handling Errors

**Symptom**:
- Footage shifts color when metadata lost
- White balance incorrect (magenta/green cast)
- Exposure looks wrong

**Root cause**:
- REVEAL uses scene metadata for rendering
- Lost metadata = defaults applied (wrong WB, EI)
- ARRIRAW requires metadata for decoding

**Common metadata loss scenarios**:
1. **Transcoding**: Wrong settings strip metadata
2. **Archiving**: XML/sidecar files separated from media
3. **LTO backup**: Metadata not included in backup set
4. **CDN transfer**: Metadata files not uploaded

**Detection**:
- White balance looks wrong (check Kelving)
- Exposure seems off (check EI)
- Color cast across all clips (metadata default)

**Solution**:
1. Restore metadata from backup
2. Re-transcode with correct settings (preserve metadata)
3. Manually enter WB/EI from camera report (last resort)

**Prevention**:
- Always use "ARRIRAW" workflow (not RAW)
- Keep camera reports with scene metadata
- Test transcoding workflow before production
- Archive metadata alongside media (same folder)

### ALF-2 vs Standard ND Confusion

**ALF-2** [ARRI Light Filter - 2nd generation: motorized internal ND filtration system] vs external ND:

**Symptom**:
- Exposure compensation incorrect
- Color shift when changing ND
- Inconsistent exposure across takes

**Root cause**:
- ALF-2 compensation not applied correctly
- Camera expects ALF-2 density, external ND used
- Mixed ALF-2 and external ND in same scene

**Detection**:
- T-stop matches but exposure varies
- Color temperature shifts with ND changes
- Viewfinder shows "ND" icon but external ND on lens

**Solution**:
1. Use ONLY ALF-2 OR external ND, not both simultaneously
2. If using external ND, disable ALF-2 (set to "Clear")
3. Re-meter exposure with correct ND compensation
4. Match color temperature across ND changes (use filters from same manufacturer)

**Prevention**:
- Decide on ND strategy before shoot
- Document ND used (ALF-2 or external)
- Label ND filters clearly
- Test ND system before production

## Camera Specifications (2024-2025)

### ALEXA 35 (2023)

**Sensor**: ALEV IV, Super 35 (4.6K)
- Resolution: 4608 × 2592
- Photosite size: 4.6µm × 4.6µm
- Dynamic range: 17 stops (claimed), 16.5 stops (measured)
- Base ISO: 800
- EI range: 160-3200

**Recording formats**:
- **ARRIRAW**: 3.2K Open Gate, 4.6K 16:9, 4.6K 4:3 (anamorphic)
- **ProRes**: 4444 XQ, 4444, 422 HQ, 422, 422 LT

**Frame rates**:
- Open Gate: 1-120 fps (4.6K)
- 16:9: 1-120 fps (4.6K)
- 4:3: 1-110 fps (3.2K)

**Features**:
- REVEAL color science v4
- LogC4 encoding (17 stops)
- ALF-2 internal ND (0.6-2.4ND)
- ARRI Textures (2-8) noise reduction
- Ethernet (10GbE), USB-C

### ALEXA LF (2018, current production 2024)

**Sensor**: ALEV III, Full Frame (4.5K)
- Resolution: 4448 × 3096
- Photosite size: 6.0µm × 6.0µm
- Dynamic range: 14+ stops
- Base ISO: 800 (dual base ISO: 800/3200 optional)
- EI range: 100-3200

**Recording formats**:
- **ARRIRAW**: 3.4K LF Open Gate
- **ProRes**: 4444 XQ, 4444, 422 HQ, 422

**Frame rates**:
- Open Gate: 1-90 fps (3.4K)
- LF 16:9: 1-90 fps (4.5K)

**Features**:
- ARRI color science v3 (pre-LogC4)
- LogC3 encoding (14+ stops)
- LWFS (Large Full-Format Sensor)
- PL and LPL lens mounts

### ALEXA 26F (2024)

**Sensor**: ALEV IV, Full Frame (6.5K)
- Resolution: 6464 × 2592
- Photosite size: 3.76µm × 3.76µm
- Dynamic range: 17 stops (claimed)
- Base ISO: 800
- EI range: 160-3200

**Recording formats**:
- **ARRIRAW**: 6.5K 3:2 Open Gate
- **ProRes**: 4444 XQ, 4444, 422 HQ, 422

**Frame rates**:
- Open Gate: 1-60 fps (6.5K)

**Features**:
- REVEAL color science v4
- LogC4 encoding
- Higher resolution than ALEXA 35 (6.5K vs 4.6K)
- Smaller photosites (3.76µm vs 4.6µm) - potential noise trade-off

## Best Practices (2024-2025)

### Exposure Strategy

1. **ETTR (Expose To The Right)**:
   - Maximize signal without clipping
   - Use false color to verify (skin tones at 70-80% IRE)
   - Reserve 2-3 stops highlight headroom

2. **EI selection**:
   - EI 800 for most situations (optimal SNR)
   - EI 1600 for bright scenes (high-key)
   - EI 400 for dark scenes (low-key, more highlight headroom)

3. **Monitoring**:
   - Use LogC4 monitoring LUT on set
   - Verify exposure with waveform monitor
   - Check skin tones on calibrated display

4. **Documentation**:
   - Camera report: EI, WB, ND, filtration
   - Lens data: T-stop, focal length
   - Scene metadata for post reference

### Color Management

1. **Scene-referred workflow**:
   - Apply LogC4 IDT first (ACES or manufacturer LUT)
   - Grade in scene-linear or log space
   - Apply display transform last (Rec.709, P3, HDR)

2. **Metadata preservation**:
   - Archive ARRIRAW with XML metadata
   - Keep camera reports with media
   - Test transcoding workflow before production

3. **Look management**:
   - Use ARRI Look Library for on-set reference
   - Import looks as grading starting point
   - Never bake looks into master
   - Preserve LogC for future remastering

### Codec Selection

**ARRIRAW** (use for):
- Feature films (high-budget)
- VFX-heavy shots (green screen, CGI)
- Color-critical work (commercial, fashion)
- Archival projects (future-proofing)

**ProRes 4444 XQ** (use for):
- Television drama
- Documentary with budget constraints
- Web series with high quality requirements
- Easier workflow than ARRIRAW

**ProRes 422 HQ** (use for):
- Reality TV
- Behind-the-scenes content
- Dailies generation
- Review copies

## Mini Glossary

- **LogC4** [Logarithmic Curve 4th generation]: ARRI's latest log encoding for ALEXA 35 with 17-stop dynamic range, single curve for all exposure scenarios
- **REVEAL** [ARRI's next-generation color science engine]: v4+ required for LogC4 decoding, includes spectral characterization and illuminant-aware processing
- **EI** [Exposure Index]: ISO-like setting for exposure metering, adjusts monitoring LUT but not recorded data (distinct from sensor gain)
- **ALF-2** [ARRI Light Filter - 2nd generation]: Motorized internal ND filtration system (0.6-2.4ND) integrated into sensor module
- **K1.8** [Kelvin 1.8]: ARRI's proprietary white balance system allowing fine adjustment around standard Kelvin values (2000-10000K)
- **AWB** [Auto White Balance]: NOT recommended for narrative work; use manual white balance for consistency
- **AWG** [ARRI Wide Gamut]: ARRI's native color space, slightly larger than P3, optimized for skin tone accuracy
- **ALVF-2** [ARRI Linear Variable Filter system 2nd generation]: Technical name for ALF-2 motorized ND system
- **ARRI Look Library**: Predefined 3D LUTs designed by ARRI for specific creative looks, compatible with all ALEXA cameras
- **ALEV** [ARRI CMOS Sensor]: ARRI's proprietary sensor design (ALEV III, ALEV IV) with large photosites for high SNR
- **ARRIRAW**: ARRI's uncompressed RAW format preserving sensor data before de-Bayering, requires metadata for decoding
- **ProRes**: Apple's intermediate codec family (4444 XQ, 4444, 422 HQ, 422, 422 LT) used for in-camera recording
- **Dynamic range**: Ratio between maximum signal and noise floor, ARRI claims 17 stops for ALEXA 35 (measured 16.5 stops)
- **SNR** [Signal-to-Noise Ratio]: Ratio of signal power to noise power, higher = cleaner image, 57dB at 18% gray for ALEXA 35
- **Photosite**: Individual light-sensitive element on sensor, larger photosites (4.6µm on ALEXA 35) = better light gathering and SNR
- **Base ISO**: Sensor's native sensitivity without gain applied, 800 for ARRI cameras (optimal SNR)
- **Dual Base ISO**: Optional feature on ALEXA LF (800/3200), optimized circuitry for two sensitivity ranges
