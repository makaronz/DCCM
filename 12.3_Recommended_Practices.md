# 12.3 Recommended Practices Checklist

Print this. Tape it to your DIT cart. Check items off as you go. Forget something here and you'll hear about it in post.

## Pre-Production

- [ ] **Define the Color Workflow**
  - [ ] ACES or camera-native? Decide before the first test.
  - [ ] Working color space: ACEScct, ARRI Wide Gamut/Log C, Sony S-Gamut3.Cine, or other.
  - [ ] Target displays and delivery formats: Rec. 709, DCI-P3, HDR10, Dolby Vision? Know the spec matrix.
  - [ ] LUTs/CDLs: who builds them, who approves them, how they travel to post.

- [ ] **Camera Tests**
  - [ ] Shoot tests with the actual camera, lenses, and lighting you'll use.
  - [ ] Check dynamic range, noise at target ISO, skin tone reproduction.
  - [ ] Record format: RAW, Log, or both? Pick one and stick to it.

- [ ] **Monitor Setup**
  - [ ] Calibrate every monitor before the shoot. Rec. 709 for SDR, DCI-P3 for cinema, Rec. 2020 for HDR.
  - [ ] Match the viewing environment: dark room for grading, controlled lighting for on-set.
  - [ ] Document calibration dates and target values.

- [ ] **LUT/CDL Prep**
  - [ ] Build or source LUTs before day one.
  - [ ] Test LUTs on actual footage, not test charts alone.
  - [ ] Name LUTs clearly: `PROJECT_LOOK_v01.cube`, not `lut_final_FINAL.cube`.

- [ ] **Talk to Everyone**
  - [ ] DP: what's the intended look? Reference images?
  - [ ] DIT (if that's not you): what's the cart setup? Monitor chain?
  - [ ] Colorist: what workflow do they prefer? What transforms?
  - [ ] Post supervisor: delivery specs, timelines, platform requirements.

## Production (On-Set)

- [ ] **Camera Setup**
  - [ ] White balance: measure with a gray card, don't guess.
  - [ ] ISO: base ISO is your friend. Only deviate if you have to.
  - [ ] Recording format: verify it's what you tested.
  - [ ] Metadata: record it all. Camera settings, lens data, LUT names.

- [ ] **Exposure**
  - [ ] Waveform monitor: watch the top, watch the bottom.
  - [ ] False color: know what the colors mean on your specific camera.
  - [ ] Zebras: set to the right level for your format (usually 95–100% for log).
  - [ ] ETTR for log: expose as far right as possible without clipping. Clipped highlights are gone forever.

- [ ] **On-Set Color**
  - [ ] Monitors calibrated? Check.
  - [ ] LUT box in the chain? Teradek COLR, BoxIO, or equivalent.
  - [ ] Viewing LUT loaded? The DP should see the intended look, not flat log.
  - [ ] CDLs recorded? Every change needs to be documented and passed to post.
  - [ ] Live grading software running? Pomfort Livegrade, Colorfront, or equivalent.

- [ ] **Data Management**
  - [ ] Offload footage immediately. Don't let cards pile up.
  - [ ] Three copies minimum: one on set, one near-set, one off-site or cloud.
  - [ ] Checksums: verify every transfer. MD5, xxHash, or equivalent.
  - [ ] Naming convention: `PROJECT_SCENE_TAKE_DATE_CAMERA`. Consistent. No spaces.
  - [ ] Log everything: card numbers, transfer times, verify status.

- [ ] **Wireless Video**
  - [ ] LUT applied before transmission if possible. Wireless systems compress — give them a finished-looking image.
  - [ ] Check latency. Director and DP need to see motion in real time.

## Post-Production (Editorial)

- [ ] **Ingest**
  - [ ] Import with LUTs/CDLs applied. Editorial should see the same look as on set.
  - [ ] Organize media: bins by scene, day, or camera. Pick one and stick to it.

- [ ] **Offline Edit**
  - [ ] Proxies for smooth playback. Keep the originals linked.
  - [ ] LUTs on proxies too. Don't let editorial guess the look.

- [ ] **Communication**
  - [ ] Regular check-ins with the colorist. Share notes, reference frames, CDL lists.

## Post-Production (Color Grading)

- [ ] **Conform**
  - [ ] Online from original camera files, not proxies.
  - [ ] Verify timecode sync. One frame off and the whole reel is wrong.

- [ ] **Color Management**
  - [ ] ACES? Load the correct OCIO config. Camera-native? Load the correct IDT/ODT.
  - [ ] Working space: wide gamut (ACEScg, DaVinci Wide Gamut) for maximum flexibility.
  - [ ] Timeline color space set correctly before the first correction.

- [ ] **Grading**
  - [ ] Reference on-set LUTs/CDLs. The DP already made decisions — respect them.
  - [ ] Consistency: shot-to-shot, scene-to-scene, reel-to-reel.
  - [ ] HDR: watch highlights. 1000 nits is not 100 nits. What's bright in SDR becomes blinding in HDR.
  - [ ] Skin tones: check the vectorscope. They should fall on the skin tone line.

- [ ] **Monitoring**
  - [ ] Calibrated reference monitor. Dark room. No windows.
  - [ ] Client monitor? Tell them it's not reference. Better yet, don't let them judge color on it.

- [ ] **Output**
  - [ ] One master per delivery spec. Netflix wants Dolby Vision. Amazon wants HDR10+. Apple wants both plus Atmos.
  - [ ] SDR fallback: still required for every platform. Don't skip it.
  - [ ] IMF packaging for streaming. DCP for cinema. ProRes masters for archival.

- [ ] **Quality Control**
  - [ ] Watch the whole thing. Every frame. Banding, artifacts, dead pixels, color drift.
  - [ ] Check the first and last frame of every shot. That's where errors hide.
  - [ ] Audio sync, burn-ins, titles, captions — color is not the only thing that matters.

## Archival

- [ ] **Three Copies Minimum**
  - [ ] Original camera files.
  - [ ] Project files (Resolve project, timeline, node tree).
  - [ ] Rendered outputs (all delivery versions).
  - [ ] LUTs, CDLs, color decisions, documentation.

- [ ] **Storage**
  - [ ] LTO-9 tape for long-term (30+ year lifespan, zero idle power).
  - [ ] Cloud cold storage for accessibility (Glacier, Archive, Coldline).
  - [ ] One copy off-site. Fire, flood, theft — it happens.

- [ ] **Verification**
  - [ ] Check integrity every 2–3 years. LTO degrades. Hard drives fail. Cloud services change terms.
  - [ ] Document what you have, where it is, and how to access it.

- [ ] **Format**
  - [ ] Archive in original camera format + high-quality mezzanine (ProRes 4444 XQ or DNxHR 444).
  - [ ] Include all metadata, LUTs, and color documentation.

## Sustainability (New — Chapter 14)

- [ ] **Measure Your Footprint**
  - [ ] DIT cart power consumption: use a power meter, log daily usage.
  - [ ] Cloud rendering: pick low-carbon regions (Iceland, Norway, Oregon, Iowa).

- [ ] **Reduce Energy**
  - [ ] Turn off equipment during breaks and overnight. Sleep mode still burns power.
  - [ ] Use SSD storage instead of HDD. Lower power, faster, more reliable.
  - [ ] Deliver dailies digitally (cloud/local network) instead of shipping hard drives.

- [ ] **Efficient Codecs**
  - [ ] Delivery: HEVC or AV1 for 4K+ (30–50% less bandwidth than H.264).
  - [ ] Archival: LTO-9 tape beats spinning disks for long-term storage cost and energy.

---

This checklist covers the essentials. Every project is different — adapt as needed. The key is consistency: do it the same way every time, document what you did, and communicate with the team. Color management fails when someone assumes instead of verifies.
